# 00 术语表（L3 · 通用）

> 阅读其他文档前先看这里。英文为游戏内原文，中文为统一译名。
> v2.4（2026-11-11）清理：删除“蛇形选秀/顺位/自由球员/新秀选秀/交易截止”等旧赛季术语，改为训练师之旅的构筑/赛季术语。

## 球场与比赛

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 综合评分 | OVR | 主位置加权总评，25~99 |
| 位置 | POS | PG 控卫 / SG 分卫 / SF 小前 / PF 大前 / C 中锋 |
| 体力 | STA / Energy | 影响效率的消耗性资源，疲劳后效率下降 |
| 蓄力条 | Meter | 投篮按住蓄力，甜点释放为完美出手 |
| 完美出手 | Perfect Release | 甜点区松开，必进率高（2分 .94 / 3分 .86） |
| 干扰 | Contest | 防守者贴近降低命中率，按距离/防守/体型计算 |
| 火热手感 | On Fire | 连进 3 球触发，命中率 +0.25，持续 5 次命中 |
| 死球 | Dead Ball | 换人生效的时机 |
| 进攻时限 | Shot Clock | 24 秒，违例交换球权 |
| 加时 | Overtime | 平分进入，每节 = 常规节长的一半 |

## 属性克制（宝可梦机制）

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 属性 | Type | 每只 1~2 个，克制倍率取双方最优 |
| 效果拔群 | Super Effective | 2× 倍率，增强冲撞与必杀 |
| 效果不好 | Not Very Effective | 0.5× |
| 免疫 | Immune | 0×，冲撞必失败 |
| 冲撞/推人 | Shove | 加速+抢断，受克制影响（见 05） |
| 招牌技 | Signature Move | 按主属性获得的必杀，共 6 类（见 05） |
| 必杀槽 | Special Bar | 得分/抢断/盖帽/助攻积攒，满后释放 |

## 构筑与成长

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 推荐位置 | Recommended Pos | 数据里写的 `pos`，用于图鉴/商店/AI/默认首发 |
| 适配度 | Fit | 八维按位置权重的加权和 / 99；0~1 |
| 主位置 | Main Pos | 推荐位置；显示与默认排阵使用 |
| 副位置 | Secondary Pos | 八维最优位置与推荐位置差距 <0.05 时显示 |
| 全能度 | Versatility | 五位置 OVR 的平均值；传说高、普通专精低 |
| 稀有度 | Rarity | 普通/稀有/传说；不是属性倍率，是基础值+成长效率+全能度+获取难度 |
| 成长预算 | Growth Budget | 等级 196 + 训练 40 + 道具 20 = 256 上限 |
| 等级成长 | Level Bonus | 每级随机 2 项 +1，存入 `mon.bonus` |
| 训练点 | Training Point | 篮球币购买，补随机加点的歪；≤ 等级÷2，上限 40 |
| 道具点 | Item Point | 成就/赛季/活动获得，跨阈值；上限 20 |
| 战力 | Power | `monPower` = 有效属性按实际位置算出的 OVR；匹配/排行用 |
| 同种唯一 | Species Unique | 全档案（队伍+仓库）不能有两只同 dex |

## 赛季与关卡

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 道馆队 | Gym Team | 8 支道馆球队之一；每队每季与玩家交手 1 次 |
| 积分榜 | Standings | 9 队按胜场/净胜分/胜负关系排序 |
| 半决赛 | Semifinal | 季后赛 1v4、2v3，胜者进总决赛 |
| 总决赛 | Final | 季后赛最后一场，胜者为赛季总冠军 |
| 四天王联队 | Elite Four Team | 独立挑战球队，击败后拿传说奖励；不参加积分榜/季后赛/总冠军 |
| 模拟 | Simulate | 一键出比分；常规赛/季后赛/四天王可用；80% 奖励 |
| 总冠军 | Champion | 总决赛胜者；与四天王挑战分离 |
| 赛季 | Season | 9 队单循环 9 轮（玩家 8 场 + 1 轮轮空）+ 季后赛 + 四天王挑战；结束后进入下一赛季 |
| 常规赛 | Regular Season | 9 队单循环 9 轮（玩家 8 场 + 1 轮轮空），前 4 进季后赛 |
| 季后赛 | Playoffs | 半决赛 1v4、2v3；胜者进总决赛 |
| 四天王挑战 | Elite Challenge | 8-0 集齐 8 徽章解锁，独立 1 场，可重试 |
| 徽章 | Badge | 常规赛击败馆主获得，8 枚=8-0，解锁四天王挑战；每赛季重置 |

## 收集与经济

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| 篮球币 | Coins | 主货币；比赛/里程碑/成就产出 |
| 图鉴两态 | Dex States | 无记录=剪影；有记录=点亮 |
| 结缘三通道 | Three Recruitment Paths | 孵蛋 / 商店直购 / 战胜签约 |
| 孵蛋 | Egg | 购买时定 dex，时间到揭示；离线照孵 |
| 树果 | Berry | 固定 XP 道具，可留存、可喂仓库 |
| 里程碑 | Milestone | 按累计收集数阶梯发币，不按首次点亮 |
| 撞车 | Duplicate | 已有同种；蛋折 50%，签约改 XP/树果 |
| 仓库 | Box | 无上限；可训练/吃树果，不可比赛 |
