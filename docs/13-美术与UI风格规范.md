## 1. 风格定位（核心洞察）

**"复古像素内容 × 现代扁平容器"双层包装**（见 01/02/04）：

- 游戏世界内容（角色、地图、精灵）走 GBC/GBA 世代复古像素风，低饱和自然色；
- UI 面板层走现代手游扁平风：深蓝底、圆角面板、高饱和强调色、清晰信息层级。

两者反差是这套视觉成立的关键：像素内容提供怀旧氛围，现代面板保证可读性与操作效率。本项目同构适用——**比赛引擎画面保持像素风，所有系统界面用现代面板包装**。

## 2. 色彩体系

| 角色 | 规格 | 来源 |
| --- | --- | --- |
| 面板主底色 | 深海军蓝（约 #1E3A6E ~ #2A4A8A），面板外层更深、内嵌区块更浅形成递进 | 01 主菜单面板、04 详情页 |
| 页面最底层 | 近黑的暗色（游戏画面压暗或纯深底），让蓝色面板浮出 | 03 弹窗背后、04 顶部 |
| 主强调/CTA | 明黄色（约 #F5C542），用于主按钮、资源数字、进度条、星星、选中态描边 | 03 返回按钮、05 选中的"阿罗拉"地区页签、06 进度条 |
| 次级按钮 | 亮蓝色底 + 白字 | 01"开始探险" |
| 第三级按钮 | 灰蓝底 + 白字（弱操作） | 04"它是你的伙伴" |
| 正文中性色 | 白色，带轻微投影保证在蓝底上的可读性 | 全部截图 |
| 数值强调色 | 黄色（资源量、等级数字） | 06 任务奖励、02 统计数值 |

**使用纪律**：蓝色系承担 90% 面积；黄色只给"可点击/可获取/重要数值"；红粉只给生命与危险态。杜绝大面积高饱和杂色。

## 3. 排版布局

- **竖屏单手纵向流**：顶部状态区 → 中部展示区 → 下部操作面板（01）。
- **顶部 HUD 三分法**：左上=单位头像+血条+等级，中上=计时，右上=暂停（02）。宽度各占约 1/3，互不侵占。
- **主菜单上展示、下操作**：上半区为角色卡片（含"更换"角标），下半区为操作面板（01）。
- **操作面板 2 列网格**：每格=彩色小图标+功能名+一行灰色小字副标题（01：图鉴 1/966、强化、招募、任务、排行、设置）。
- **列表页 = 页签 + 筛选行 + 卡片网格**（05）：地区页签（胶囊按钮组）→ 稀有度筛选 chips → 3 列等宽卡片网格，卡片内自上而下：编号/剪影/???。
- **弹窗规范**（03）：居中圆角深蓝面板；标题居中；统计区 2 列小卡片（浅蓝底圆角内嵌）；奖励区单独一个内嵌块；按钮纵向排列，主操作在下、广告类成对横排。
- **详情页层级**（04）：顶部小卡片（当前持有个体）→ 大展示框 → 特性说明 → 名字+类型徽章 → 属性条列表 → 招式图标网格 → 底部全宽操作按钮。信息从"看"到"用"自上而下。
- **间距节奏**：面板外边距约屏宽 5%，区块间距 ≈ 1.5×条目间距；紧凑但不贴边。

## 4. 字体与文字样式

- 界面标题可用**像素/游戏感艺术字**（01 的游戏 logo 带描边与立体感）；系统面板标题用常规粗体即可（03"你倒下了…"、06"任务"）。
- 层级：页面标题（大号粗体居中）→ 区块标题（中号）→ 条目正文（常规）→ 副标题/说明（小号、灰蓝弱化色）。
- 所有正文带轻微深色投影（text-shadow），保证蓝底可读。
- 数字（资源、进度、等级）一律黄色并略大于周围文字。

## 6. 图标与插画风格

- **精灵图**：16-bit 像素风、正面站姿、透明底（04 大图、05 剪影）。
- **UI 小图标**：非像素的简化彩色 icon（宝可梦球、星、奖杯、齿轮、喇叭），带轻微立体/高光，与像素内容不冲突——**UI 图标不必像素化**，保持圆润友好即可（01 菜单格）。
- **地图 tile**：低饱和自然色（草绿、土棕、灰石），饱和度刻意低于 UI 面板，避免抢视觉焦点（02）。
- **剪影处理**：未获得内容用纯黑剪影+「???」，制造收集欲（05）。

## 8. 校验清单（新界面实现时自查）

1. 面板是否深蓝底圆角、外深内浅递进？
2. 黄色是否只出现在可点击/重要数值上？
3. 主按钮是否全宽黄色、次级蓝色、弱操作灰蓝？
4. 文字是否带投影、数值是否黄色加大？
5. 弹窗是否"标题居中→统计内嵌卡→奖励块→纵排按钮"？
6. 页面是否"页签→筛选→网格"三段式？
7. UI 图标是否圆润友好（不强行像素化）、游戏内容是否保持像素风？
8. 素材是否全部自制/原创（未搬运参考游戏资源）？

## 本项目 UI 架构定稿（2026-11-11 用户）
- **采用「单屏主页 + 弹窗卡片」**，不使用底部 tab 架构（docs/09 与 GDD S0b 同步更新）。
- 主页：顶部资源条 → 中部展示卡（精灵+属性徽章+更换） → 下部菜单面板（开始比赛通栏；图鉴/队伍、商店/孵蛋、背包/设置 两两一行）。
- 子页（图鉴/队伍/商店/孵蛋/背包）为浮层圆角卡片弹窗，主页保持在背后；设置/成就/金币/更换/详情为同风格弹窗。
- 弹窗卡片统一尺寸：宽 `min(560px, 100vw - 16px)`、高 `min(84dvh, 720px)`；内容超出时仅卡片内部滚动。统一入场动画：遮罩淡入 + 卡片上浮缩放（`pj-modal-scrim-in` / `pj-modal-card-in`）。
- 主页不显示赛程进度条；比赛全屏、赛后结算整页。
- 基准尺寸 390×844，只做手机竖屏。
- 2026-11-12：所有宠物卡显示稀有度角标；图鉴新增「传说 / 稀有 / 普通」筛选 chips。

## 主题切换（2026-11-12）

- 主题文件互斥加载：`css/retro.css`（复古体育）、`css/classic.css`（暗黑原版）、`css/valorant.css`（战术）、`css/stardew.css`（星露谷）、`css/terraria.css`（泰拉瑞亚）、`css/black.css`（墨黑），同一时间只挂载一个 `link#ui-theme-style`。
- 正式版入口：设置 → 外观 → 界面风格（复古体育 / 墨黑），切换即时生效。
- 体验版：URL 加 `?themes=1` 后开放全部六套主题。
- 持久化：`localStorage["pokedunk.uiTheme"]`，启动时由 `index.html` 内联脚本在首屏渲染前恢复，避免闪回。
- 星露谷主题令牌：页面底色 `#ecd6a8`、羊皮纸面板 `#f2dcae` / `#fff7e2`、深木 `#8a5a2b`、主操作绿 `#5f8f3f`、正文深棕 `#2f1d0c`、次要文字 `#5e4020`；面板 2–3px 木框 + 圆角 + 内侧奶油高光，按钮带底部木牌阴影。
- 对比度纪律：正文与次要文字全部使用深棕实色，不再用低透明度白/棕；标题放在独立羊皮纸木牌上，避免直接压在球场背景上；卡片底色比页面底色亮一级，保证文字与背景分层。
- 复古体育主题（2026-11-12 调研后新增）：参考 Retro Bowl 的像素体育管理界面（报纸/记分板式信息层级、硬边卡片、强对比像素字）、Mario Hoops 3-on-3 的街机篮球配色、宝可梦掌机菜单的图标可读性。令牌：报纸底 `#f4ead2` / 卡片 `#fff8e8`、墨黑 `#1c241e`、球场绿 `#1f5c3a`、橙色强调 `#d98324`、次要文字 `#6e6a5b`；所有卡片使用 2px 墨线边框 + 4–5px 硬投影，按钮为绿底墨边，标题为报纸报头式双横线。

- 泰拉瑞亚主题令牌：深空蓝紫底 `#0d1024` / `#1b1f3a`、石质面板 `#2b2e4d` / `#1c1d33`、木框 `#6b4a2f` / `#2a1a0e`、金色强调 `#e8c170`、正文米白 `#e8e0c8`、次要文字 `#a89b84`、生命绿 `#6fbf4a`；全部使用 0 圆角与像素斜面 `box-shadow`（左上亮、右下暗），背景叠加星空点阵。

- 新增 `js/ui/theme.js`：`loadTheme / applyTheme / setTheme`，负责主题文件切换与持久化。

## 双版本模式（2026-11-12 定案）

- **正式版（默认）**：只显示「复古体育 / 墨黑」两套主题，设置页始终有「外观」页签；默认复古体育。
- **体验版**：在 URL 后加 `?themes=1` 时显示全部六套主题（复古体育 / 墨黑 / 暗黑原版 / 战术 / 星露谷 / 泰拉瑞亚），选择写入 `pokedunk.uiTheme`。
- 实现：同一套代码，通过 `VISIBLE_THEMES` 控制可见主题列表，不复制两份工程；`classic.css` 只做少量收口，主体沿用原版深蓝 + 金色体系。
- 发布时无需改代码：正式版直接用默认地址，体验版用于内部对比/演示；暗黑原版、战术、星露谷、泰拉瑞亚四套实验主题不会出现在正式版外观列表。
