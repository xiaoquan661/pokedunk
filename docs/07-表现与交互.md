# 07 表现与交互（L1 · 表现层）

> 渲染、操作、音频、汉化层、平台适配的技术实现。

## 渲染

- Canvas 2D，逻辑坐标系 94×50 英尺，按容器缩放（object-fit: cover）
- 球场/观众席/城市横幅由代码绘制，迷你球馆 + 彩带演出
- 演示模式（Attract Mode）：菜单背景自动打比赛
- 必杀特写：镜头推近 + 斜切能量带 + 大立绘冲拳/残影 + 「必杀」大字 + 招式名，约 2 秒；特写期间比赛暂停，双方共用
- 设置 → 比赛 →「必杀动画」可关闭，关闭后不播放特写、不推镜头、不暂停比赛
- 分享卡：canvas 绘制 → 大图预览（Lamps 版仅本地预览）

## 操作（三端）

| 端 | 映射 |
| --- | --- |
| 键盘 | WASD/方向键移动 · J/空格 投篮 · K 传球 · L 抢断 · Shift 加速 · I/E 必杀 · P/Esc 暂停 |
| 触屏 | 虚拟摇杆 + 5 按钮（RB 加速 / Y 必杀 / X 投篮 / B 抢断 / A 传球），攻防文案自动互换 |
| 手柄 | 左摇杆 + A/X/B/Y + RB/LB/扳机加速 + Start 暂停 |

- 防守切换默认**手动**；可在设置 → 比赛切回自动。

无本地双人（引擎预留 users[2]，UI 未开放）。

## 音频

- 音效与环境音：原版 `ln` 音频控制器移植到 `js/platform/audio.js`，WebAudio 合成运球/打铁/扣篮/蜂鸣/哨声/抢断/盖帽等；比赛自动起停观众底噪与进球喝彩
- 必杀音效：专用合成音轨（能量蓄力 → 重击命中 → 高频尾音 + 观众欢呼），与 2 秒特写同步；受设置 → 声音的「音效」总开关控制，与「必杀动画」开关相互独立
- 背景音乐：原版 4 首程序化球场曲目移植到 `js/platform/music.js`，菜单轮播、比赛静音、按曲自动切换；首次用户手势后解锁 AudioContext
- 解说：原版 35 段 mp3 已复制到 `announcer/`，按需 `fetch + decodeAudioData`（扣篮/盖帽/三分/压哨/跳球/节末等）
- 开关：设置 → 声音，持久化键 `pokedunk.muted` / `pokedunk.music` / `pokedunk.announcer`；解说开关同步写入引擎读取的 `pokejam.announcer` 兼容键

## 汉化层（zh.js）

- 机制：词典（短语/短标签/304 名字/属性词）+ MutationObserver 改 DOM + fillText/strokeText/measureText 猴补 + 中文字体替换
- 性能：已优化（2026-11-04）——翻译缓存 + 合并正则，图鉴页点击主线程阻塞 **1904ms → 238ms**（实测）
- 长期方向：渐进原生汉化（先数据表后 UI，绕开逻辑字段）；新页面性能预算 ≤150ms（98 号规范）

## 平台适配（Lamps）

- 状态栏安全区：HUD 优先 `--sat`（`getStatusBarInfo` 下发），env() 兜底
- 云存档：`sync.js` 双写（localStorage 即时 + 云端防抖 2s），时间戳新者胜
- 激励视频：ad-sign 机制保留；训练师之旅第一版不接新场景（树果折扣/孵蛋加速后续再做）
- 合规：无外联、无自由文本输入、无下载、无剪贴板；详见《改造方案-Lamps.md》

## 视口

- `viewport-fit=cover`（刘海屏必需）
- ES Module，需 Chrome 80+ / iOS 14+
