# 五 Tab 导航与冒险地图（S100）

## 底部导航

固定 5 个 Tab：

1. **冒险**
2. **球队**
3. **图鉴**
4. **商店**
5. **锦标赛**

原「主场」与「赛程」合并为「冒险」，不再单独存在赛程 Tab。

## 冒险页

冒险页同时承担地图解锁与关卡选择：

- 顶部地区切换：关都 / 城都
- 当前地区徽章进度与当前路线进度
- 每日挑战、任务作为两个独立小入口
- 纵向道馆节点：
  - 已通关：勾选、收起
  - 当前道馆：高亮，展开 5 个小关
  - 未解锁：灰色锁定
- 当前道馆 CTA：查看当前关卡，进入原有路线详情页
- 8 徽章后出现「挑战四天王」入口

### 地区

- **关都**：完整可玩。
- **城都**：显示 8 个道馆锁定节点；完成关都 8 枚徽章后开放。当前版本内容接入中。

## 道馆路线页

- 嵌入 Tab 后与冒险地图统一使用 12px 横向内边距，进出页面不再跳宽。
- 顶部显示地区徽章进度；道馆卡显示第 X/8 馆；新增 5 关路线进度条，标出已完成 / 当前 / 未解锁节点。
- 当前关标题保留阶段名，并标注关卡类型（野生 / 训练家 / 补给 / 馆主）。

## Tab 返回规则

- 通过底部 Tab 或 Tab 内分类导航可直接到达的页面不显示返回键：冒险地图、球队首发 / 训练 / 背包 / 生涯、图鉴 / 成就、商店 / 孵蛋、锦标赛。
- 只有需要逐级返回的页面保留返回键：路线详情、任务，以及背包物品详情等更深层页面。
- 分类页通过底部 Tab 或分类导航切换；路线 / 任务返回所属 Tab 页面。

## Tab 内分类导航

- 球队 / 图鉴 / 商店的二级分类统一使用「线框图标 + 文字 + 金色下划线」的横向导航，不再使用四等分方框按钮。
- 当前分类金色高亮并带短下划线，未选中分类降低对比度；切换分类不改变底部 Tab 状态。

## 商店刷新

- 每日货架跨天懒刷新；刷新结果会立即写回存档。
- 同一天重复进入商店不会重摇货架，也不会重置已购数量。

## 暂缓项

- 快速比赛入口暂时隐藏，代码保留，后续再接回。
- 每日挑战仍是独立小玩法入口，不并入地图节点。
- 任务保持独立入口，不占底部 Tab。
