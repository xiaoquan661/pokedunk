# 08 教学与开局（跨层 · 引导流程 L2 + 表现 L1）

> 新玩家第一次 10 分钟的体验设计。

## 教程（Tutorial）

- 触发：首次进入训练且教程完成标记（设置类小键）未置位时**自动开始**
- 内容：以教程模式跑完全部 7 项练习
- 专用配置（tutorialConfig）：
  - 预设满配队伍（取 OVR 前 5）
  - 每节 90 秒、难度 rookie、关闭体力、固定随机种子 20261031、练习模式
- 表现：顶部教练条（头像 + 提示 + 跳过/退出）、3-2-1 倒计时、结果卡（New best!）
- 完成后引导："该打一场真比赛了 → 进入训练师之旅·第一馆"

## 训练（Training）

7 项练习，每项限时 40~60 秒、3 档星级（`stars:[a,b,c]` 阈值）：

| # | 练习 | 内容 |
| --- | --- | --- |
| 1 | 脚步 Movement | 跑向每个发光点 |
| 2 | 上篮 Layups | 杀到篮下上篮 |
| 3 | 跳投 Jump Shots | 圆圈处蓄力出手 |
| 4 | 传球 Passing | 传给箭头指向队友 |
| 5 | 空接 Alley-Oop | 加速+传球吊给篮下队友 |
| 6 | 防守 Defense | 站在人与篮筐之间 |
| 7 | 抢断 Steals | 贴身掏球 3 次 |

- 教练台词全套：intro / tip / rep / great / good / retry
- 最佳星级存于设置类小键（新项目键名实施期定），可"全部跑一遍"（Run all）

## 开局引导链（v2.5：五位置选伙伴 → 训练师之旅）

```
教程（自动） → 五位置选初始伙伴 → 训练师之旅·赛季（9 队单循环 9 轮 + 季后赛 + 四天王挑战）
     ↘ 训练（教程延伸：操作不熟随时回来练）   ↘ 快速比赛（更多 tab，无存档沙盒）
```

- 营地 tab 常驻"新手？先做教程"入口
- **训练定位=新手教程的延伸**：不是独立模式，不承载长线目标；新玩家教程后若操作没吃透，通过训练补课再上路
- **五位置选伙伴定位=开局建队**：先选位置，再获得该位置对应的 Lv1 伙伴；不再限制御三家，选完直接进入常规赛第一轮
- **快速比赛定位=娱乐沙盒**：无成长压力的自由玩法，老玩家随手一局；入口在"更多"tab，不接入构筑

### 五位置初始伙伴

| 位置 | 伙伴 |
| --- | --- |
| PG | 杰尼龟 |
| SG | 小火龙 |
| SF | 妙蛙种子 |
| PF | 腕力 |
| C | 小拳石 |

- 初始伙伴 Lv1 零 bonus，推荐位置直接设为所选位置，避免越位惩罚。
- 位置只决定开局槽位和培养方向，之后仍可在队伍页拖动调整；进化时按新种族更新推荐位置。
- 开局卡不显示属性标签，位置统一用字母；卡面显示该位置下的初始 OVR。
- “组织/投射”等定位文案没有机制作用，已移除，避免增加理解负担。
- 属性克制说明保留在设置页。

## 局外新手引导（v3，2026-11-12）

- 触发：新存档首次进入主页；状态存于 `save.guide = { v: 1, step, done }`，完成后同时写 `save.onboarded = true`。
- 范围：只讲局外流程，不进入比赛内操作；比赛内仍保留原「首场 30 秒新手引导」。
- 6 步（全部在主页）：
  1. 资源与目标（顶栏：篮球币来源与用途、徽章来源）
  2. 队伍与位置（10 只上限、前 5 首发、八项能力与推荐位置）
  3. 每日商店（精灵 / 蛋 / 树果、孵化时长与传说概率）
  4. 孵蛋与成长（槽位、购买/广告扩容、树果经验与训练点）
  5. 每日挑战（每日阵容、首胜与任务金币）
  6. 开始比赛（指向「设置 → 说明」查看赛制与结算）
- 交互：全部用「下一步」推进；可随时跳过。
- 主页顶栏新增「导引」按钮，任何存档都可随时重看，不再只能等首次进入。
- 指引浮层不拦截页面点击；高亮目标自动滚动到视口，卡牌自动放在目标上方或下方。
- 中途离开保留进度；回主页显示「继续指引」。导航到其他页面时浮层自动清理。
- 复古体育主题下，指引卡牌同步使用报纸米色底、墨线边框和绿色主按钮。

## 新手友好机制

- 新手任务：主页金币 `+` →「获取金币」→「新手任务」，完成 1/2/3/4 场比赛各送一只自选开局精灵，补齐首发 5 人；集齐后改领 100 币。
- rookie/pro 难度自带移动辅助（assist）与橡皮筋追分（catchup）
- 自动换人默认开启，不用管轮换
- 开局五选一没有超时压力；选完直接进入第一馆
- **首场 30 秒新手引导**：无比赛记录且未看过引导时，首场比赛显示「移动 → 投篮 → 传球/必杀」三段非阻塞提示，每 10 秒切换，可跳过；只出现一次，不打断比赛
- 难度随时可改（快速比赛赛前界面）
