## v3.0 定稿摘要（2026-11-26）

### 稀有度 A+ 全能度

- 普通 / 稀有 / 传说三档；所有人单项 99 封顶，不做硬上限。
- 普通=专精，稀有=多面，传说=全能 + 早熟。
- 传说用 dex 白名单，不进每日商店；普通蛋 1% / 高级蛋 6% 独立概率；四天王通关解锁本地区 2 选 1。
- 展示：`主位置 OVR / 全能度`。

### 位置方案一

- `pos` = 推荐位置；八维算 `fit`。
- 291 条审计：176 完全一致、91 邻位 <0.02、24 邻位 0.02~0.035、0 条 ≥0.05。
- 邻位显示“推荐 X · 副 Y”；越位最低 90%。
- 五位置齐羁绊要求 `fit(实际) / fit(推荐) ≥ 0.90`。

### 成长额度

- 等级随机 98 + 训练 138（98 自由 + 40 购买）+ 道具 20 = 256 上限。
- 每级 +1 随机 +1 自由训练；购买训练 ≤ 4 + 等级÷2（最多 40），价格随已购买点数上涨；道具每种最多 4 次。
- 单项 99 封顶。

### 羁绊

- 首发 5 人整队触发；最多 3 条，同类别只取 1 条。
- 场内 2%~5%；场外只做 QoL，不做产币倍率。
- 条件/效果全部写进游戏说明。

### 主线

- 每个地区按顺序打 8 个道馆；每个道馆先清 5 关路线，再打馆主。
- 当前徽章数决定下一个道馆；馆主胜利给徽章并解锁下一馆。
- 8 徽章解锁四天王；四天王通关即地区冠军，前往下一地区。
- 道馆队战力用原版分布；地区切换后 +2 补强。
- 四天王共享地区传说池；战斗与模拟按现有规则结算。
- 冠军后重置徽章；保留成长/羁绊/图鉴。
