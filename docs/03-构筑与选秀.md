# 03 构筑系统（L2 · 稀有度 / 成长 / 位置 / 羁绊）

> v2.4（2026-11-11）重写。旧“赛季选秀 / 10 队蛇形 / 60 秒计时 / `pokejam.draft.v1` / 我的选秀队 / 快速比赛三开局”章节全部作废——GDD v2.4 已删除经典赛季，开局改为御三家三选一 + 结缘三通道。
> 本文只写训练师之旅（journey）的构筑系统；快速比赛是无存档沙盒，不接入本文的稀有度/训练/道具/羁绊/位置适配。
> 数值公式与验收基线见 `docs/02-数值系统.md` 附“构筑系统数值增补（v2.4）”。

## 1. 构筑总览

构筑 = 四层，从“抽到什么”到“怎么练”到“怎么摆”到“怎么搭”：

| 层 | 系统 | 回答的问题 | 主要产出 |
| --- | --- | --- | --- |
| L1 | 稀有度 | 这只精灵的起点和上限是什么 | 基础八维、获取难度、全能度 |
| L2 | 成长 | 怎么把它练强 | 等级、训练、道具 |
| L3 | 位置 | 它该打哪个位置 | 推荐位置、适配度、越位惩罚 |
| L4 | 羁绊 | 五个人怎么搭 | 队伍条件、团队增益 |

设计目标：

- 普通精灵靠“专精”立足，稀有精灵靠“多面”，传说精灵靠“全能 + 早熟”。
- 不让单一系统压过其他：等级约 76%、训练约 16%、道具约 8%；羁绊最多 3 条、单条 2%~5%。
- 战斗手感优先：数值差距解释约 30%~40% 的胜负，操作占 60%~70%。

## 2. 稀有度（A+ 全能度）

### 2.1 三档

| 档位 | 判定 | 单项上限 | 定位 | 获取 |
| --- | --- | --- | --- | --- |
| 普通 | 基础 OVR < 70 | 99 | 专精：主位置 3~4 项 99，换位置弱 | 商店/蛋常见 |
| 稀有 | 基础 OVR 70~84 | 99 | 多面：6~8 项 99，可打 2~3 个位置 | 商店少量/蛋稀有/战胜签约 |
| 传说 | 传说/幻之 dex 白名单 | 99 | 全能 + 早熟：八维 99，五位置都能打 | 不进每日商店；蛋 1% 独立概率；联赛冠军/四天王共享赛季 2 选 1 |

- 传说档用 dex 白名单，不用“OVR ≥ 85”自动判定，避免把强力非传说误标。
- 稀有度不是属性倍率；差异来自基础值、成长效率、全能度、获取难度。
- 同种唯一仍然生效；传说全档案一只。
- 传说白名单、冠军轮换顺序与蛋池 1% 概率已定案。

### 2.2 展示

- 队伍卡/详情页：`主位置 OVR / 全能度`。
- 普通：主位置 99 / 全能 75；传说：主位置 99 / 全能 95。
- 主位置 = 推荐位置；全能度 = 五位置 OVR 平均。
- 超梦：传说档，高基础、约 Lv40 八维全满；定位 = 毕业奖励/快速比赛神器/图鉴荣誉，不是常规养成核心。

### 2.3 边界

- 所有人单项 99 封顶，不做稀有度硬上限。
- 普通可以主位置 99，但全能度低；换位置按第 4 节扣。
- 传说不能通过每日商店获得；普通蛋/高级蛋各有 1% 独立概率孵出传说；联赛冠军或四天王可触发当期 2 只传说自选（共享池）。

## 3. 成长

### 3.1 等级

- XP 曲线沿用 `xpToNext(level) = 60 + 25 × (level - 1)`。
- 每级随机 2 项 +1，沿用 `rollGrowth`，单项 99 封顶。
- 等级成长只写入 `mon.bonus`，不混入训练/道具。

### 3.2 训练

| 项 | 规则 |
| --- | --- |
| 上限 | 40 点，且 ≤ 等级 ÷ 2 |
| 获取 | 篮球币购买；无每周限制 |
| 价格 | 动态上涨：`20 + 5 × 该精灵已训练点数` |
| 分配 | 玩家指定八维；单项 99 封顶 |
| 重置 | 返还 80% 训练点，不退币；道具不返还 |
| 适用范围 | 队伍与仓库精灵均可训练；仓库精灵仍不可比赛 |

- 训练的作用是“补随机加点的歪”，不是主战力来源。
- 训练点写入 `mon.train.stats`，`mon.train.points` 记录已投入。

### 3.3 道具

| 项 | 规则 |
| --- | --- |
| 上限 | 20 点 |
| 单种道具 | 每只精灵最多 4 次 |
| 来源 | 成就/赛季/活动；商店每周限 1 |
| 分配 | 道具决定加点类型（如力量/速度/技巧），玩家选择目标 |
| 适用范围 | 队伍与仓库精灵均可使用 |

- 道具是“跨阈值”工具（如 95→99），不做无限来源。
- 写入 `mon.item.stats`，`mon.item.used` 记录每种道具次数。

### 3.4 总预算

| 来源 | 上限 | 占比（Lv99） |
| --- | --- | --- |
| 等级 | 196 | 约 76% |
| 训练 | 40 | 约 16% |
| 道具 | 20 | 约 8% |
| 合计 | 256 | 上限，不是保底 |

- 普通档基础低，256 点通常只能把 3~4 项练到 99；传说档基础高，约 72 点即可八维全满。
- 单项 99 封顶；任何来源都不能突破。

### 3.5 边界

- 不可赊账/负数；购买前校验。
- 失败/退出不产币，避免“刷币买训练”。
- 进化保留 `bonus` / `train` / `item`；`pos` 更新为新形态推荐位置。
- 旧档迁移：`train` / `item` 缺失补零；`assign` 缺失按 `mon.pos` 初始化。

## 4. 位置

### 4.1 推荐位置 + 适配度

- 数据里的 `pos` = **推荐位置**，用于图鉴、商店、AI 组队、默认首发。
- 八维算 **适配度**：

```text
fit(pos) = Σ(成长值[i] × POSITION_WEIGHTS[pos][i]) / 99
```

- `POSITION_WEIGHTS` 沿用 `engine/data/positions.js`，不另调。
- `mainPos = mon.pos`；`bestPos = argmax fit`。
- 若 `fit(bestPos) - fit(mainPos) < 0.05`，显示“推荐 X · 副 Y”；不视为矛盾。
- **v2.6 双推荐位置**：球队卡显示 `recommendedPositions(mon)` = 初始八维（种族值）适配度前二，格式 `C/PF`。只读种族值，不随等级/训练/道具变化；推荐位置是提示，不是上场限制。

### 4.2 数据审计

- 291 条：176 完全一致、91 邻位 <0.02、24 邻位 0.02~0.035、0 条 ≥0.05。
- 最大差距 0.035，全部为 PF↔C、SF↔SG、SF↔PG 等相邻位置。
- 结论：原版数据可信；只有双位置倾向，没有真正矛盾。

### 4.3 越位倍率

```text
recFit = fit(mon.pos)
if assignedPos == mon.pos: posMult = 1.0
else: posMult = clamp(0.90 + 0.10 × fit(assignedPos) / recFit, 0.90, 1.0)
```

- 推荐位置 100%；邻位通常 97%~100%；明显越位最低 90%。
- 位置倍率只作用于比赛有效值，不改变存档成长值。

### 4.4 实际位置、槽位与自动排阵

- `save.assign[monId]` 存实际位置；首发 5 人各占一个唯一槽位（PG/SG/SF/PF/C）。
- **位置即槽位，任意精灵可放任意槽**；放在非推荐位置按 §4.3 计算越位倍率，不做硬限制。
- 球队页按参考阵型 3+2 展示：上排 SF/C/PF，下排 SG/PG；卡片显示 `推荐 C/PF`，底部单独显示槽位代号。
- 拖动规则（v2.6）：
  - 首发互拖 → 两张卡交换槽位；
  - 替补拖到首发槽 → 替补进入该槽，原首发回替补席；
  - 首发拖到替补卡 → 该首发换下，替补进入其槽位。
- 槽位变化后 `save.team` 前 5 人按 PG/SG/SF/PF/C 顺序同步，保证比赛阵容稳定。
- 位置调整统一在球队页完成（拖动卡片或替补换入）；详情页只展示当前槽位与推荐位置，不再提供位置页签。
- 自动排阵：队伍 10 人穷举 5 人 × 5 位置，优先总 `monPower`，其次五位置覆盖，再次全能度。
- 玩家可手动改；开赛前锁定。

### 4.5 五位置齐羁绊

- 首发 5 人实际位置覆盖 PG/SG/SF/PF/C 各 1，且每人：

```text
fit(assignedPos) / fit(mon.pos) ≥ 0.90
```

- 5 个 C 硬贴标签不算达成。
- 传说八维平均，五位置 fit 接近，天然满足全能优势。

### 4.6 进化与快速比赛

- 进化：`mons.pos` 更新；`assign` 保留，按新八维重算；不做位置熟练度，所以无投资损失。
- 快速比赛：`assignedPos = mon.pos`，倍率 1.0，不接入训练/道具/羁绊。

## 5. 羁绊

### 5.1 规则

- 只算**首发 5 人**，开赛前锁定；替补/仓库不参与。
- 最多同时生效 **3 条**，按类别各取 1 条：通用 / 属性 / 进攻 / 防守 / 经济。
- 同类别只取最高/最先满足的一条，不叠加。
- 条件与效果全部写进游戏说明，不做隐藏发现。
- 场内效果只做小额团队增益（2%~5%）；场外只做 QoL，不做产币倍率。

### 5.2 条件维度

- 系别：同系 ≥3。
- 地区：同地区 ≥3（关都/城都/丰缘/神奥/合众/卡洛斯/阿罗拉/伽勒尔/帕底亚）。
- 进化链：同进化链 ≥2（不同 dex）。
- 位置：五位置齐、双塔、跑轰等。
- 属性阈值：全队 def ≥75、C/PF blk ≥80、PG/SG/SF spd ≥85 等。

### 5.3 示例羁绊

| 羁绊 | 条件（首发 5 人） | 效果 | 类别 |
| --- | --- | --- | --- |
| 五位置齐 | PG/SG/SF/PF/C 实际位置各 ≥1，且适配度达标 | 全队有效属性 +3% | 通用 |
| 地区共鸣 | 同一地区 ≥3 | 全队有效属性 +2% | 通用 |
| 同系共鸣 | 同一属性 ≥3 | 该属性成员关键属性 +5% | 属性 |
| 进化链 | 同一进化链 ≥2（不同 dex） | 这两只关键属性 +4% | 属性 |
| 双塔 | C + PF 各 1，且两者 blk ≥80 | 全队盖帽/篮板 +5% | 防守 |
| 铁壁 | 全队 def ≥75 | 全队防守 +4% | 防守 |
| 跑轰 | PG+SG+SF 各 1，且三者 spd ≥85 | 全队速度 +4% | 进攻 |
| 御三家 | 妙蛙/小火龙/杰尼龟进化链各 ≥1 | 全队 XP +10%（场外） | 经济 |

- 具体数值与完整清单由 S13 定；上表为第一版默认。
- 同类别多条只生效 1 条，例如“五位置齐”和“地区共鸣”只能二选一。
- “进化链”在“同种唯一”下要求两个不同 dex，属于收集型羁绊；第一版可延后。

### 5.4 界面与说明

- 队伍页新增“羁绊”子页：
  - 当前首发 5 人。
  - 已激活羁绊（✓）与未达成羁绊（✗）。
  - 每条显示：条件、效果、当前进度（如“关都 4/3”）。
- 比赛开始前显示本场生效羁绊。
- 游戏说明内提供完整羁绊表，不依赖外部 wiki。

### 5.5 AI 与匹配

- AI 不需要真的凑羁绊；匹配时把玩家羁绊计入 `teamPower`，AI 用 `boost` 补平。
- 避免 AI 有羁绊导致玩家被针对，也避免 AI 没羁绊导致白嫖。

### 5.6 边界

- 替补/仓库不参与；比赛中换人不改变羁绊。
- 同种唯一仍生效；不能靠重复精灵凑羁绊。
- 场外羁绊只做 XP/孵蛋/商店格等 QoL，不做金币/经验倍率（御三家的 XP 为一次性小加成，需封顶）。

## 6. 队伍与仓库

### 6.1 结构

- 队伍 = 首发 + 替补，上限 10 人；首发 5 人，替补 5 人。
- 仓库无上限；仓库精灵可训练/吃树果，不可比赛。
- 全档案同种唯一（team + box）。

### 6.2 调动

- 队伍 ⇄ 仓库自由移动，无代价。
- 队伍不可少于 5、不可多于 10。
- 仓库交互：点击卡片查看详情；队伍有空位时「调入队伍」，队伍满 10 人时「换入队伍」→ 选择一名队员放入仓库完成交换。
- 放生第一版不做。

### 6.3 首发与替补

- 首发 5 人从队伍 10 人中手动挑选；其余为替补。
- 球队页支持拖动换位与替补换入；换位只改 `assign`/队伍顺序，不消耗资源。
- 比赛允许死球换人；替补登场不改变羁绊（羁绊在开赛前锁定）。
- 自动排阵见 4.4；自动换人沿用引擎设置。

### 6.4 快速比赛

- 无存档沙盒；不接入稀有度/训练/道具/羁绊/位置适配。
- 选队、对手、场地、观战、模拟沿用 GDD S9。
- 入口在“更多”tab，不参与图鉴/商店/孵蛋/树果/篮球币。

## 7. 战力与匹配口径

```js
growthStats(mon) = base.r + bonus + train.stats + item.stats  // 每项 0..99
posMult(mon, assignedPos) = 位置倍率（见 4.3）
effectiveStats(mon, assignedPos) = growthStats × posMult + 羁绊  // 再 0..99
monPower(mon, assignedPos) = calcOVR(assignedPos, effectiveStats)
teamPower(save) = avg(top5 monPower of team)  // 防藏强
mainOVR(mon) = calcOVR(mon.pos, growthStats)
versatility(mon) = avg(posOVR(mon, p) for p in POSITIONS)
```

- 所有页面、商店定价、匹配、排行榜只走 `monPower` / `mainOVR` / `versatility`。
- 不再用 `getPokemon(dex).ovr` 作为“当前战力”；商店定价使用种族 OVR。
- 赛季匹配公式见后续“赛季与关卡”章节（docs/05）。

## 8. 平衡目标

| 项 | 目标 |
| --- | --- |
| 数值 vs 操作 | 数值 30%~40%，操作 60%~70% |
| 等级 / 训练 / 道具 | 约 76% / 16% / 8% |
| 羁绊 | 最多 3 条，单条 2%~5%，不叠加同类 |
| 稀有度 | 普通专精、稀有多面、传说全能；不做硬上限 |
| 单一系统上限 | 不超过总战力约 15%，防止一个系统压过其他 |

## 9. 验收清单

- [ ] 单项属性 ≤99；训练 ≤40 且 ≤等级/2；道具 ≤20。
- [ ] 传说 dex 不出现在每日商店/普通蛋池。
