## 四、训练与加点

### 4.1 等级与 XP

| 项 | 数值 |
| --- | --- |
| 每级所需 XP | `15 + 6 × (当前等级 − 1)` |
| Lv1 → Lv99 总 XP | **29,988** |
| 草地挂机 | 2 XP/分钟 → **约 10.4 天/只**（不设上限） |
| 单场联赛 XP | 约 120–330（`(12+分差) × 10`） |
| 高级树果 | 800 XP/个 |
| 御三家羁绊 | 比赛 XP +10% |

- 草地 10.4 天一只满级，与“打一场 2–5 分钟给 120–330 XP”相比，挂机仍是稳定主线。
- 高级树果 800 XP ≈ 6.7 小时挂机，直接跳过时间门槛。

### 4.2 属性点预算

| 来源 | 点数 | 说明 |
| --- | ---: | --- |
| 升级随机分配 | 98 | 每级 1 点随机 |
| 升级自由点 | 98 | 每级 1 点自由 |
| 付费购买 | 40 | 9,000 币点满 |
| 道具（训练卡等） | 20 | 背包/奖励 |
| **合计** | **256** | 不含广告 |
| 广告训练 | +5 × 3 次/天 | **直接绕过上限** |

- 256 点分配到 8 维，平均 32 点/维；配合 99 级基础值，属性很容易顶到收益上限。
- 广告 +15 点/天，一周 105 点，相当于“免费多升 100 级”的点数预算。
- 付费点满 9,000 币，按日常 600 币/天算 **约 15 天**，训练深度明显拉开。

### 5.2 关键战斗公式（现行）

| 行为 | 公式 / 参数 | 备注 |
| --- | --- | --- |
| 完美投篮窗口 | `(0.012 + 投篮/100 × 0.055) × T × (火热 ? 1.7 : 1)` | T 为难度/节拍系数；白闪/震感仅投篮≥90 |
| 投篮命中 | 由完美窗口、防守干扰、距离、属性共同判定 | 详见 docs/10 |
| 抢断 | `0.1 + (防守 − 控球) / 220` | 属性差 22 点约 +10% |
| 盖帽 | 起跳时机 + 防守/终结差 | 时机权重高于属性 |
| 体力 | 加速、抢断、必杀消耗；低体力降低命中与速度 | |
| AI | 难度四档 + boost；季后赛/四天王递增 | |
| 模拟 | 奖励 ×0.8，失败无 XP | |
| 失败 | 基础币 ×20%，每日前 3 次；XP 25 | 约为胜利金币的 40% |

**问题**：
- 属性对命中的影响仍大于操作：高 OVR 队伍容错极高。
- 主线 12 分钟一场只给 18–24 币，玩家仍缺少“认真打主线”的理由。
- 失败仍有 20% 保底，配合每日 3 次，形成低成本刷币路径（金额小）。
