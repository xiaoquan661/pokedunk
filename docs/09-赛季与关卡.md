# 09 主线关卡与进度（原“赛季与联赛”）

> **S72–S73（2026-11-26）已删除联赛制。** 原 9 队单循环、轮空、积分榜、季后赛与赛季赛程弹窗全部移除，不再作为实现依据。
> 现行主线设计见 `docs/18-GDD-主线与收集.md`；本文件只保留主线关卡结构与存档兼容说明。

## 1. 现行核心循环

```text
当前地区
├─ 道馆 1 → 5 关路线 → 馆主 → 徽章 1
├─ 道馆 2 → 5 关路线 → 馆主 → 徽章 2
├─ ……
├─ 道馆 8 → 5 关路线 → 馆主 → 徽章 8
├─ 四天王挑战（可重试）
└─ 地区冠军 → 下一地区
```

- 「开始比赛」直接进入当前道馆，不经过赛程页。
- 当前徽章数决定下一个道馆，严格按顺序推进。
- 每个道馆先清 5 关路线：野生 1v1 → 路线训练家 5v5 → 补给点 → 野生 1v1 → 馆主 5v5。
- 路线关卡不推进主线；只有馆主战胜利给徽章并解锁下一馆。
- 8 徽章解锁四天王；四天王通关即地区冠军，触发冠军庆典与地区传说。
- 下一地区内容未就绪时保留冠军进度并拦截，不用旧地区馆主冒充。

## 2. 关卡数值口径

- 馆主阵容与战力沿用 `js/journey/gyms.js` 的 8 馆配置；地区切换后按 `s.no` 递增补强。
- 四天王使用 `elite` 联队配置，通关前后可重复挑战。
- 战斗机制、节长、模拟规则与结算公式（`docs/10`、`docs/02`）不变。
- 模拟/观战仍按现有规则结算，不影响主线结构。

## 3. 存档字段（`journey.season` v4）

```js
save.journey.season = {
  v: 4,
  no: 1,                 // 地区周目计数（地区切换时 +1，用于难度与传说轮换）
  phase: "regular",      // regular / done
  badges: [],            // 当前地区已获得徽章
  results: [],           // 道馆战记录（徽章页显示最近比分）
  fourKings: { unlocked, attempts, cleared, rewardClaimed, rewardGiven },
  champion: false,
  contracts, contractWins, contractDry,
  playerStats: {}, ovrBase: {}, awards: [], mvp: null,
  history: [],           // 地区冠军记录
};
```

旧档读取时会自动迁移：保留徽章、四天王、冠军、战绩、合同与统计；删除 `schedule / scheduleSeason / rounds / table / playoffs / byeRound / round`。
