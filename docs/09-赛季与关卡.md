# 09 赛季与联赛（9 队单循环 9 轮 + 季后赛 + 四天王）

> v3.1（2026-11-12）定稿。替代 v2.4 的“8 馆 × 4 小关 + 四天王 = 33 场”杯赛结构；常规赛按 9 队单循环 9 轮（每队 8 场 + 1 轮轮空）。
> 原则：**宝可梦术语保留，赛制改成篮球赛季**。道馆、馆主、徽章、四天王这些词不改；长线是 9 支队伍打一个赛季，争一个总冠军。
> 构筑与战力口径见 `docs/02-数值系统.md`、`docs/03-构筑与选秀.md`。

## 1. 赛季总结构

```text
联赛（9 支队伍）
├─ 8 个道馆队
└─ 玩家队伍

常规赛：9 轮，每轮 4 场 + 1 队轮空
        玩家打 8 场，轮空 1 轮
        ↓ 胜场 → 净胜分 → 胜负关系
前 4 名 → 季后赛
        ↓
半决赛：第 1 vs 第 4、第 2 vs 第 3
        ↓
总决赛 → 赛季总冠军

独立挑战：常规赛 8 胜 0 负 → 集齐 8 枚徽章 → 四天王挑战
```

| 阶段 | 内容 | 玩家场次 |
| --- | --- | --- |
| 常规赛 | 9 队单循环 9 轮，每轮 4 场 + 1 队轮空 | 8（另 1 轮轮空） |
| 季后赛 | 前 4 名，半决赛 + 总决赛 | 最多 2 |
| 四天王 | 独立挑战，不参与联赛 | 1（可重试） |
| 一个赛季 | 常规赛 + 季后赛 + 可选四天王 | 最多 11 |

- 常规赛每轮同时进行 4 场；玩家打完自己的比赛后，本轮其他 3 场由 AI 模拟并展示结果。
- 玩家轮空的那一轮，展示本轮其他 4 场战况，可直接进入下一轮。
- 常规赛**不能重打**，输了记负。
- 没进前 4：赛季结束，进入下一赛季。
- 季后赛被淘汰：赛季结束，进入下一赛季。
- 四天王与联赛互不影响：不参加排名、季后赛和总冠军争夺。

## 3. 常规赛

### 3.1 赛程

- 9 队单循环 = 9 轮；每轮 4 场，1 支队伍轮空。
- 玩家打 8 场（每个道馆 1 场），另 1 轮轮空。
- 每轮玩家比赛结束后，本轮其余 3 场由 AI 模拟，和玩家比分一起更新积分榜。
- 轮空轮：展示本轮其他 4 场结果，玩家可直接进入下一轮。
- 常规赛**不能重打**；输了直接记负，赛季继续。
- 中途退出 = 判负，0 币 0 XP。
- 赛程用圆桌轮转生成；同一赛季固定，不随重开变化。
- 玩家轮空轮由圆桌轮转自然生成，每个赛季位置可能不同；所有队伍都有 1 次轮空，最终都是 8 场。

### 3.2 积分榜

- 9 支队伍，每队 8 场。
- 排名规则：
  1. 胜场多者靠前；
  2. 胜场相同，净胜分高者靠前；
  3. 再相同，相互战绩胜者靠前；
  4. 再相同，球队战力高者靠前。
- 每轮结束实时更新积分榜；其他队伍的比赛按当轮战力 + 固定种子模拟，结果写入本轮战况。
- 赛季中按胜场/净胜分排序；所有队伍完成 8 场后确定前 4。
- 积分榜前 4 名进入季后赛。

### 3.3 目标战力

```text
teamPower = 队伍前 5 高 monPower 平均值
leaguePower = 原版馆主队有效战力 + (赛季数 - 1) × 2
常规赛 target = min(leaguePower, teamPower + 10)
季后赛 / 四天王 target = 原版有效战力 + (赛季数 - 1) × 2
```

- 常规赛保留软保底，防止越级墙。
- 季后赛和四天王不软保底，打不过就练。
- 难度档位只控制 AI 行为；数值差距由 `boost` 补。

## 4. 徽章

- 常规赛每击败一个道馆馆主，获得该馆 1 枚徽章。
- 8 枚徽章 = 常规赛 8 胜 0 负；不是季后赛资格门槛。
- 徽章同时是「四天王挑战」的解锁条件：**集齐 8 枚才能挑战四天王**。
- 徽章详情页展示 8 枚道馆徽章、获得状态与本赛季比分。
- 徽章在赛季重置时清空；玩家收藏、成长、图鉴保留。

## 5. 季后赛

- 常规赛前 4 名进入季后赛。
- 半决赛：
  - 第 1 名 vs 第 4 名
  - 第 2 名 vs 第 3 名
- 半决赛胜者进入总决赛；总决赛胜者为**赛季总冠军**。
- 玩家的季后赛最多 2 场；未参与的半决赛/总决赛由 AI 模拟。
- 玩家没进前 4：不进季后赛，赛季直接结束。
- 玩家半决赛被淘汰：赛季结束，进入下一赛季。
- 季后赛结果不重打。

## 6. 四天王挑战

- 解锁条件：常规赛 8 胜 0 负，集齐 8 枚徽章。
- 入口独立：赛季页单独显示「四天王挑战」，不进入积分榜、不进入季后赛。
- 对手：**四天王联队**，一支球队，打 1 场。
- 可以安排在季后赛之前打。
- 可以重试，不消耗常规赛战绩；**每个赛季只发一次奖励**。
- 入口有效期：8-0 解锁后到本赛季结束前；季后赛结束后关闭。
- 四天王胜利不计入联赛总冠军，也不改变常规赛排名。

## 7. 传说奖励

### 7.1 传说池

- 当前实际可获得的传说共 **16 只**：
  急冻鸟、闪电鸟、火焰鸟、超梦、梦幻、雷公、炎帝、水君、洛奇亚、凤王、雪拉比、拉帝亚斯、拉帝欧斯、盖欧卡、固拉多、烈空坐。
- 每赛季放出 **2 只**，**8 个赛季**轮换完；第 9 赛季循环回第 1 赛季的两只，不永久绝版。

### 7.2 两条获取线

| 获取线 | 条件 | 奖励 |
| --- | --- | --- |
| 联赛总冠军 | 赢下季后赛总决赛 | 本赛季传说池「2 选 1」 |
| 四天王挑战 | 8-0 后击败四天王 | 本赛季传说池「2 选 1」 |

- 两条线共享同一个赛季传说池（A、B 两只）。
- 先完成的一条线：从 A/B 中 **2 选 1**。
- 后完成的另一条线：直接获得本赛季剩下的那一只。
- 两条线都完成：当赛季 A、B 两只全拿；8 个赛季收齐 16 只。
- 只完成一条：当赛季拿 1 只；另一只保留为“待领取”，不会消失。
- 传说领取后直接进队伍；队伍满 10 只时进仓库。
- 重复传说折算 200 篮球币。
- 未领取的传说保留在赛季页，可补领。

### 7.3 奖励分工

| 内容 | 奖励 |
| --- | --- |
| 联赛总冠军 | 奖杯、400 币、1 个道具、赛季 MVP、传说奖励资格 |
| 四天王挑战 | 四天王称号、400 币、1 个道具、传说奖励资格 |
| 常规赛单场 | 币 + XP + 徽章（胜） |
| 季后赛单场 | 更高币 + XP |

## 8. 奖励与防刷

### 8.1 单场奖励

| 结果 | XP 倍率 | 篮球币倍率 |
| --- | --- | --- |
| 常规赛胜 | ×5.0（约 60–110） | ×0.7（约 35–48） |
| 季后赛半决赛胜 | ×7.0 | ×1.5 |
| 总决赛胜 | ×8.0 | ×2.0 |
| 四天王胜 | ×8.0 | ×3.0 + 400 |
| 失败 | 25 XP（模拟失败 0） | 每日前 3 次 20%，之后 0 |
| 中途退出 | 0 | 0 |

- 模拟胜利：奖励 ×0.8。
- 观战：按模拟口径结算（×0.8）。
- 常规赛不能重打，因此取消“重复通关递减”和“首通奖励”。
- 四天王可重试，但每个赛季只发一次奖励。

### 8.2 防刷

- 退出 = 判负，0 币 0 XP。
- 失败安慰奖每天前 3 次 20%，之后 0。
- 不做“每周 AI 悄悄成长”；赛季 +2 写进公式，透明。

## 9. 存档字段

```js
journey.season = {
  v: 3,
  no: 1,
  phase: "regular" | "playoffs" | "done",
  round: 0,                  // 下一轮 0..8（共 9 轮）
  byeRound: 4,              // 玩家轮空轮次；由圆桌轮转生成，每赛季可能不同
  schedule: [               // 9 轮对阵（每轮 4 场 + 轮空队）
    { round, bye, games: [{ a, b }] }
  ],
  scheduleSeason: 1,        // 赛程对应的赛季号
  rounds: [                 // 每轮战况（4 场 + 轮空队）
    { round, bye, games: [{ a, b, sa, sb }] }
  ],
  results: [                 // 玩家 8 场常规赛
    { venue, win, myScore, oppScore, sim, at }
  ],
  table: [                   // 9 队积分榜
    { id, name, abbr, power, w, l, pf, pa, isMe }
  ],
  playoffs: {                // 进季后赛后生成
    seeds: [id, id, id, id],
    semis: [{ a, b, sa, sb, winner }],
    final: { a, b, sa, sb, winner } | null,
    champion: id | null
  } | null,
  fourKings: {
    unlocked: false,         // 8 徽章解锁
    attempts: 0,
    cleared: false,
    rewardClaimed: false
  },
  badges: [],                // 本赛季道馆徽章
  champion: false,           // 玩家是否联赛总冠军
  history: []                // 历届冠军/MVP/战绩
}
journey.legend = {
  claimed: [],               // 已完整领取的赛季
  taken: { 1: [dex] },       // 每赛季已拿走的传说
  pending: [{ season, choices: [dex, dex] }] // 待领取 2 选 1
}
```

- 每打完一场自动存档，赛季可中断续打。
- 赛季结束进入下一赛季时：`no + 1`，重置 `round / results / table / playoffs / fourKings / badges / champion`；保留队伍、等级、训练、道具、羁绊、图鉴、金币、`assign`。
- 旧存档不做迁移；测试阶段旧赛季进度直接按新赛季重开。

## 10. UI

### 10.1 赛季页

- 顶部：`第 N 赛季 · 常规赛 第 R/9 轮`，右侧徽章计数 `X/8 徽章`（可点击打开徽章详情）。
- 本轮战况：显示本轮 4 场比分、轮空队；玩家比赛高亮。
- 玩家轮空轮：显示“本轮轮空”，并展示本轮 4 场其他队伍战况。
- 积分榜：9 行，显示排名、队伍、胜-负、净胜分；前 4 名有季后赛标记；玩家行高亮。
- 赛程：9 轮（玩家 8 场 + 1 轮轮空），显示对手、结果、比分；当前轮高亮；不提供重打按钮。
- 季后赛：进季后赛后显示半决赛/总决赛对阵与比分。
- 四天王入口：
  - 未解锁：`集齐 8 枚徽章解锁`；
  - 已解锁：`四天王挑战 · 第 X 次`；
  - 已通关：`已通关`;
  - 赛季结束：`本赛季四天王入口已关闭`。
- 赛季结束：显示总冠军与「进入下一赛季」。

### 10.2 赛前对阵页

- 展示双方战力、对手首发、我方首发与替补、预计胜率。
- 卡片右上角显示 OVR。
- 该页只读，不可调整阵容；点「继续」开球，「返回」回主页。
- 常规赛/季后赛/四天王共用该页，只是对手和标题不同。

### 10.3 比赛结果

- 显示比分、奖励、下一场。
- 常规赛结束后同时显示“本轮其他战况”（本轮其余 3 场比分）和更新后的积分榜。
- 玩家轮空轮显示“本轮轮空”，并列出本轮 4 场其他队伍战况。
- 常规赛胜利且拿到徽章：继续播放徽章获得动画。
- 季后赛结束时显示总冠军/赛季结束。
- 四天王胜利时显示传说 2 选 1 入口。
- 联赛总冠军同样显示传说 2 选 1 入口。

### 10.4 观战与模拟

- 常规赛、季后赛、四天王均可观战；一键模拟仅在进入比赛后提供，赛季页不再直接显示模拟按钮。
- 模拟/观战按 80% 奖励结算；常规赛结果同样计入积分榜。
- 常规赛不能重打；模拟失败就是负场。
