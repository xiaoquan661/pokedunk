## 1. 成长线总览

| 线 | 上限 | 作用 | 主要来源 |
| --- | --- | --- | --- |
| 等级随机 | 98 点 | 随机成长 | 比赛 XP，每级 +1 随机 |
| 训练 | 138 点 | 玩家指定成长 | 升级每级 +1 自由点；另可购买最多 40 点 |
| 道具 | 20 点 | 跨关键阈值 | 成就/赛季/活动 |
| 合计 | 256 点 | 上限，不是保底 | 单项 99 封顶 |

- 训练/道具对队伍与仓库精灵均可用；仓库精灵仍不可比赛。
- 等级成长只写 `mon.bonus`；训练写 `mon.train`；道具写 `mon.item`。三者分开存，便于审计和重置。

## 2. 经验与等级

- 升级曲线：`xpToNext(level) = 15 + 6 × (level - 1)`（S18 下调 34%，升级更快）。
- 每次升级：按位置权重随机 1 项 +1（`rollGrowth`），同时获得 1 点自由训练点；单项 99 封顶。
- 赛后货币/树果（S25）：胜利金币按原公式 ×0.5；胜利额外给普通树果 1~3 个（分差≥10 多 1 个，30% 再多 1 个），15% 额外给高级树果 1 个；失败 25% 给普通树果 1 个；胜利道具掉落改为 50% 概率。
- 赛后 XP（基础口径）：
  - 胜：`12 + min(10, 分差)`。
  - 负：`25`（模拟失败 0）。
  - 实际发放按赛季关卡缩放：常规赛 ×5.0、半决赛 ×7.0、总决赛 ×8.0、四天王 ×8.0（见 docs/09）。
- 进化：达到进化等级后，精灵详情页出现「进化」按钮，由玩家手动触发；`bonus` / `train` / `item` 保留；`pos` 更新为新形态推荐位置；等级不变。
  - 三段进化：第一段 Lv15、第二段 Lv30。
  - 两段进化：第一段 Lv25。
  - 引擎原表 2/3/4 级仅作数据源，游戏层由 `js/systems/evo-rules.js` 按链深度覆盖。
  - 允许同家族不同阶段同时持有；若进化后目标 dex 已存在，则与已有同种融合：保留正在进化的个体，等级/经验/随机加点取高，已有个体的训练点转入返还池，道具优先转移、超出上限折算 100 币/点。
- 等级 99 封顶；满级后 XP 不再累积。

## 3. 训练

| 项 | 规则 |
| --- | --- |
| 上限 | 免费点（每获得 1 级 +1，孵蛋/合同按来源保底等级补发）+ 购买点 `min(40, 4 + 等级÷2)`；满级合计 138 点 |
| 获取 | 每升 1 级送 1 点自由训练；另可用篮球币购买，无每周限制 |
| 价格 | 只对购买点收费，`10 + 3 × 已购买点数`；买满 40 点合计 2,740 币 |
| 分配 | 玩家指定八维；单项 99 封顶；优先消耗返还点、自由点，最后扣币 |
| 重置 | 返还 80% 训练点，不退币；道具不返还 |
| 适用范围 | 队伍与仓库精灵均可训练 |

- 训练从“补歪”升级为第二成长线：升级随机 +1，另一半由玩家自由分配。
- UI 显示：构筑栏为 `训练 32/138 · 自由点 12`；训练页说明购买价、自由点、返还点与重置规则。

## 5. 篮球币

### 5.1 来源

| 途径 | 规则 |
| --- | --- |
| 比赛胜利 | `20 + 0.5 × 对手OVR`，再乘赛季关卡系数（docs/09） |
| 比赛失败 | 每天前 3 次给胜利奖励的 20%；之后 0；中途退出 0 |
| 图鉴里程碑 | 按累计收集数阶梯发（10/30/50/100/150/200/291，奖励表见 §9） |
| 成就奖励 | 成就页手动领取：33 项成就覆盖闯关 / 养成 / 收集 / 对战 / 签到 / 每日挑战；每项给金币（50–400）或道具（高级树果、孵蛋加速券、高级精灵蛋），支持一键领取 |
| 每日挑战 | 每日首胜 +100；当日任务完成 1 场 +30 / 赢 1 场 +60 / 单场扣篮 2 次 +40；挑战分只记最高，不重复产币 |
| 撞车折算 | 孵蛋撞车 = 商店价 50%；战胜签约撞车 = XP/树果（不退币） |

### 5.2 支出

- 商店直购、蛋、树果、蛋槽解锁、训练点、道具。
- 购买前校验；不可负数、不可赊账。
- 无上限；随存档云同步。

### 5.3 防刷边界

- 退出 = 判负，0 币、0 XP。
- 失败安慰奖每天限 3 次，防止“秒退刷币”。
- 重复通关奖励递减（docs/09）。
- 战胜签约每对手每天最多 1 次；撞车不再退币。
- 商店日期回拨不防御（休闲游戏接受）；蛋的 dex 在购买时定死，改时间不能刷稀有。

### 5.4 广告点

| 广告点 | 奖励 | 限制 |
| --- | --- | --- |
| 金币广告 | +100 篮球币 | 每日 5 次 |
| 孵蛋加速 | 孵化时间 -2 小时 | 每日 2 次 |
| 孵蛋立即完成 | 当前蛋直接可孵化 | 每日 1 次 |
| 训练自由点 | 指定精灵自由训练点 +5 | 每日 3 次 |
| 合同免费多签 | 在合同之外，免费额外再签一只 | 每日 1 次 |
| 败局复活 | 撤销本场败局并重打 | 每日 1 次 |
| 商店刷新 | 重摇当日 5 格货架 | 每日 1 次 |
| 赛后双倍 | 本场篮球币 ×2（不含 XP/徽章/签约） | 每日 2 次，仅真人比赛 |

- 共 10 类广告点位；金币广告入口仍在主页金币旁的 `+` →「获取金币」。
- 新增点位每日次数存 `pokedunk.adCaps`，与各面板原有计数独立。

### 5.5 七日签到

- 入口：主页「每日任务」→ 面板顶部签到卡；主页入口显示「签到待领」。
- 每天可签一次，连续天数累计；第 1 天必得随机稀有精灵（OVR 85+），第 3、7 天必得随机传说精灵（已集齐或队伍/仓库满则改发高级蛋 ×2）。
- 其它天奖励：普通树果 ×2 / 普通蛋 ×1 / 高级树果 ×1 / 高级蛋 ×1 / 高级树果 ×2。
- 状态存 `save.signin = { streak, lastDate }`，中断后从第 1 天重新累计。
- 每日任务全部完成时额外发放高级精灵蛋 ×1（每日一次）。

### 5.6 新手任务

- 入口：主页金币 `+` →「获取金币」→「新手任务」。
- 一次性，完成比赛场次后解锁；每档自选一只开局精灵（杰尼龟 / 小火龙 / 妙蛙种子 / 腕力 / 小拳石），共 4 档，加上初始伙伴正好补齐 5 人首发。
- 场次门槛：1 / 2 / 3 / 4 场；不要求胜利。
- 已拥有同一只时不再出现；五只全部拥有后，每档改领 100 币。
- 自选精灵按对应位置放入空首发槽；首发已满则进入队伍替补。

- 若直接获得的是进化后形态，入队等级抬到该形态最低进化等级：三段第二形态 Lv.15 / 最终形态 Lv.30；两段进化形态 Lv.25，并补发对应等级的随机成长与自由训练点（不再是“等级高但属性没长”）。宝宝进化来的基础形态（皮卡丘、皮皮等）仍按 Lv.1。
- 已有该 dex：直购不可买；蛋/签约走撞车规则。
- 传说 dex 不进入直购；普通蛋 1% / 高级蛋 6% 独立概率；联赛冠军或四天王可触发当期 2 只传说自选（共享池）。
