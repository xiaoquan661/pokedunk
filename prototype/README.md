# 底部 Tab UI 原型

这是 v3.0.0 UI 改造的静态可点击原型，不接入存档、比赛和业务逻辑。

## 打开方式

在项目根目录启动静态服务器：

```powershell
python -m http.server 8123
```

然后访问：

```text
http://127.0.0.1:8123/prototype/ui-tabs.html
```

## 已覆盖

- 390 × 844 手机竖屏舞台
- 固定 App 壳：顶部教练/金币/通知/设置
- 5 个底部 Tab：主场、球队、赛程、图鉴、商店
- Tab 内二级页：球员详情、训练、背包、生涯、路线、快速比赛、每日任务、每日挑战、教练档案
- 图鉴地区折叠、筛选条、已结缘/未遇见状态
- 设置与通知使用临时底部弹层
- 可点击返回、购买提示、自动换防开关

## 说明

- 原型只使用静态示例数据。
- 不是正式游戏入口，不会修改 `pokedunk.save.v1`。
- 确认视觉和层级后，再逐页迁移到正式代码。
