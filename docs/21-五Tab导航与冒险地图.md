# 五 Tab 导航与冒险地图（S100）

## 底部导航

固定 5 个 Tab：

1. **冒险**
2. **球队**
3. **图鉴**
4. **商店**
5. **锦标赛**

原「主场」与「赛程」合并为「冒险」，不再单独存在赛程 Tab。

## 冒险页

冒险页同时承担地图解锁与关卡选择：

- 顶部地区切换：关都 / 城都
- 当前地区徽章进度与当前路线进度
- 每日挑战、任务作为两个独立小入口
- 纵向道馆节点：
  - 已通关：勾选、收起
  - 当前道馆：高亮，展开 5 个小关
  - 未解锁：灰色锁定
- 当前道馆 CTA：查看当前关卡，进入原有路线详情页
- 8 徽章后出现「挑战四天王」入口

### 地区

- **关都**：完整可玩。
- **城都**：显示 8 个道馆锁定节点；完成关都 8 枚徽章后开放。当前版本内容接入中。

- 球队精灵卡不再写死深蓝底，改为主题纸色 + 属性色轻微混色；黑色主题下为近黑卡面。

## Tab 返回规则

- 5 个 Tab 的根页面不显示返回键：冒险地图、球队首发、图鉴、商店、锦标赛。
- 只有二级页保留返回键：训练 / 背包 / 生涯 / 孵蛋 / 成就 / 路线详情 / 任务。
- 根页面通过底部 Tab 切换；二级页返回所属 Tab 根页面。

## 商店刷新

- 每日货架跨天懒刷新；刷新结果会立即写回存档。
- 同一天重复进入商店不会重摇货架，也不会重置已购数量。

## 暂缓项

- 快速比赛入口暂时隐藏，代码保留，后续再接回。
- 每日挑战仍是独立小玩法入口，不并入地图节点。
- 任务保持独立入口，不占底部 Tab。
