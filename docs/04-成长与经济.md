# 04 成长与经济（L2 · 训练师之旅）

> v2.4（2026-11-11）重写。旧“生涯/交易/自由市场/新秀选秀/合约到期/退役/AI 每周成长”章节作废——经典赛季已删除，交易/自由市场/选秀不进入训练师之旅第一版。
> 成长数值见 `docs/02-数值系统.md` 附；构筑规则见 `docs/03-构筑与选秀.md`；赛季结构见 `docs/09-赛季与关卡.md`。

## 1. 成长线总览

| 线 | 上限 | 作用 | 主要来源 |
| --- | --- | --- | --- |
| 等级 | 196 点 | 主成长 | 比赛 XP |
| 训练 | 40 点 | 补随机加点的歪 | 篮球币购买 |
| 道具 | 20 点 | 跨关键阈值 | 成就/赛季/活动 |
| 合计 | 256 点 | 上限，不是保底 | 单项 99 封顶 |

- 训练/道具对队伍与仓库精灵均可用；仓库精灵仍不可比赛。
- 等级成长只写 `mon.bonus`；训练写 `mon.train`；道具写 `mon.item`。三者分开存，便于审计和重置。

## 2. 经验与等级

- 升级曲线：`xpToNext(level) = 60 + 25 × (level - 1)`。
- 每次升级：按位置权重随机 2 项 +1，沿用 `rollGrowth`；单项 99 封顶。
- 赛后 XP（基础口径）：
  - 胜：`12 + min(10, 分差)`。
  - 负：`25`（模拟失败 0）。
  - 实际发放按赛季关卡缩放：常规赛 ×5.0、半决赛 ×7.0、总决赛 ×8.0、四天王 ×8.0（见 docs/09）。
- 进化：达到进化等级后自动进化；`bonus` / `train` / `item` 保留；`pos` 更新为新形态推荐位置；等级不变。
  - 三段进化：第一段 Lv8、第二段 Lv16。
  - 两段进化：第一段 Lv12。
  - 引擎原表 2/3/4 级仅作数据源，游戏层由 `js/systems/evo-rules.js` 按链深度覆盖。
- 等级 99 封顶；满级后 XP 不再累积。

## 3. 训练

| 项 | 规则 |
| --- | --- |
| 上限 | 40 点，且 ≤ 4 + 等级 ÷ 2 |
| 获取 | 篮球币购买；无每周限制 |
| 价格 | 动态上涨：`20 + 5 × 该精灵已训练点数` |
| 分配 | 玩家指定八维；单项 99 封顶 |
| 重置 | 返还 80% 训练点，不退币；道具不返还 |
| 适用范围 | 队伍与仓库精灵均可训练 |

- 训练是“补歪”，不是主战力：等级加点随机，训练把歪掉的点补到该去的位置。
- UI 显示：构筑栏为 `训练 18/40`；训练页说明当前单价、下一点价格、`4 + 等级÷2` 上限与重置规则。

## 4. 道具

| 项 | 规则 |
| --- | --- |
| 上限 | 20 点 |
| 单种道具 | 每只精灵最多 4 次 |
| 来源 | 赛季徽章/冠军/四天王掉落；商店暂不售 |
| 分配 | 道具决定加点类型（力量/速度/技巧/防守/篮板），玩家选择目标 |
| 适用范围 | 队伍与仓库精灵均可使用 |

- 道具是“跨阈值”工具（如 95→99），不做无限来源。
- 五种道具：力量（终结）/ 速度 / 技巧（投篮）/ 防守 / 篮板，每种最多 4 次，合计 20 点。

## 5. 篮球币

### 5.1 来源

| 途径 | 规则 |
| --- | --- |
| 比赛胜利 | `20 + 0.5 × 对手OVR`，再乘赛季关卡系数（docs/09） |
| 比赛失败 | 每天前 3 次给胜利奖励的 20%；之后 0；中途退出 0 |
| 图鉴里程碑 | 按累计收集数阶梯发（10/30/50/100/150/200/291，奖励表见 §9） |
| 收集成就 | 一次性：首只传说、集齐某系、集齐某进化链等 |
| 每日挑战 | 每日首胜 +100；当日任务完成 1 场 +30 / 赢 1 场 +60 / 单场扣篮 2 次 +40；挑战分只记最高，不重复产币 |
| 撞车折算 | 孵蛋撞车 = 商店价 50%；战胜签约撞车 = XP/树果（不退币） |

### 5.2 支出

- 商店直购、蛋、树果、蛋槽解锁、训练点、道具。
- 购买前校验；不可负数、不可赊账。
- 无上限；随存档云同步。

### 5.3 防刷边界

- 退出 = 判负，0 币、0 XP。
- 失败安慰奖每天限 3 次，防止“秒退刷币”。
- 重复通关奖励递减（docs/09）。
- 战胜签约每对手每天最多 1 次；撞车不再退币。
- 商店日期回拨不防御（休闲游戏接受）；蛋的 dex 在购买时定死，改时间不能刷稀有。

### 5.4 广告点

| 广告点 | 奖励 | 限制 |
| --- | --- | --- |
| 金币广告 | +40 篮球币 | 每日 5 次 |
| 孵蛋加速 | 孵化时间 -30 分钟 | 每日 2 次 |
| 商店刷新 | 重摇当日 5 格货架 | 每日 1 次 |
| 赛后双倍 | 本场篮球币 ×2（不含 XP/徽章/签约） | 每日 2 次，仅真人比赛 |

### 5.5 新手任务

- 入口：主页金币 `+` →「获取金币」→「新手任务」。
- 一次性，完成比赛场次后解锁；每档自选一只开局精灵（杰尼龟 / 小火龙 / 妙蛙种子 / 腕力 / 小拳石），共 4 档，加上初始伙伴正好补齐 5 人首发。
- 场次门槛：1 / 2 / 3 / 4 场；不要求胜利。
- 已拥有同一只时不再出现；五只全部拥有后，每档改领 100 币。
- 自选精灵按对应位置放入空首发槽；首发已满则进入队伍替补。

## 6. 每日商店

| 项 | 规则 |
| --- | --- |
| 货架 | 6 格：2 精灵 + 普通蛋 + 高级蛋 + 普通树果 + 高级树果 |
| 刷新 | 懒刷新：读取时比较 `shop.date` 与本地日期，不一致即重刷；另可看广告手动刷新 1 次/天 |
| 定价 | 精灵按种族 OVR 分档：<60 = 80 / 60–69 = 120 / 70–79 = 180 / 80–89 = 240 / 90+ = 320；普通蛋 70 / 高级蛋 220 / 普通树果 30 / 高级树果 90 |
| 货架构成 | 2 精灵优先未拥有；第 1 格必为普通档（OVR<70），第 2 格 55% 稀有；按 OVR 加权，低 OVR 更常见 |
| 购买 | 币足够 + 同种唯一；入队（队满入仓）+ 图鉴点亮 + 扣币 |
| 已拥有 | 精灵格优先刷未拥有；已拥有槽位置灰；可看广告重摇货架 1 次/天 |
| 传说 | **传说 dex 不进商店货架**；普通蛋 1% / 高级蛋 3% / 四天王首通自选 / 战胜签约 |
| 边界 | `soldFlags` 记录当日已售格；已售格不再出售 |

- 商店只卖未养成个体（Lv1、零 bonus、零训练/道具）。
- 价格使用种族 OVR，不使用玩家当前养成值。

## 7. 孵蛋

| 项 | 规则 |
| --- | --- |
| 槽位 | 默认 1 槽；可花 600 币购买 1 槽 + 看广告送 1 槽，顺序不限，上限 3 |
| 购买 | 买蛋进入**待孵栏 `eggs.stock`**，不自动占槽；槽满仍可购买 |
| 放入 | 玩家在孵蛋页选择一颗蛋放入空槽；`startTs` 从放入时开始 |
| 档位 | 普通蛋 30 分钟 / 高级蛋 3 小时 |
| 概率 | 普通蛋：传说 1% / 普通 70% / 稀有 30%；高级蛋：传说 3% / 必出稀有 |
| dex | **购买时即定**，孵化只做揭示；未拥有优先；防改时间刷稀有 |
| 孵化 | 时间到点击开启；入队（队满入仓）；图鉴点亮 |
| 撞车 | 孵出已拥有 dex → 折算商店价 50%：普通蛋 35 / 高级蛋 110 / 传说 200 |
| 池子 | 普通蛋传说 1% / 高级蛋传说 3% 独立判定；未拥有优先 |
| 边界 | 离线照孵；孵中不可取消/退款；看广告每次加速 30 分钟（每日 2 次） |

## 8. 树果

| 树果 | 价格 | XP |
| --- | --- | --- |
| 普通 | 30 币 | +50 |
| 高级 | 90 币 | +300 |
| 传说 | 稀有/活动 | S13 |

- 树果入背包 `bag`，随取随用；不再即买即用。
- 可喂队伍或仓库精灵；仓库精灵不可比赛。
- 升级结算沿用数值机器：`xp += n → while(xp>=xpToNext){xp-=...; level++; rollGrowth()}`。
- Lv99 封顶，入口置灰；库存不足不可使用；不赊账。

## 9. 图鉴奖励

- 图鉴两态：无记录=剪影；有记录=点亮。
- 图鉴筛选：全部 / 已获得 / 传说 / 稀有 / 普通 / 按属性。
- 点亮本身**不给币**；奖励统一走里程碑与收集成就。
- 里程碑档位与奖励（一次性领取，存档 `save.milestones`）：

| 累计收集 | 奖励 |
| --- | --- |
| 10 | 100 币 |
| 30 | 200 币 + 力量药剂 ×1 |
| 50 | 300 币 |
| 100 | 500 币 + 速度药剂 ×2 |
| 150 | 800 币 |
| 200 | 1000 币 + 技巧药剂 ×2 |
| 291 | 2000 币 + 三系药剂 ×2 |

- 图鉴页展示进度条、下一档差距与全部档位领取列表。
- 收集成就：首只传说、集齐某系、集齐某进化链、首次 200 等（清单 S13）。
- 图鉴随 journey 存档共存亡；快速比赛不加图鉴。

## 10. 结缘三通道

| 通道 | 入口 | 触发 | 规则 |
| --- | --- | --- | --- |
| 孵蛋 | 商店蛋格/孵蛋面板 | 时间到点击 | 蛋池随机；购买时定 dex；撞车折 50% 或 XP |
| 直购 | 商店货架 | 点击购买 | 明码标价；同种唯一；队满入仓 |
| 战胜签约 | 赛后结算 | 胜利后概率触发 | 每场限 1 次、每对手每天限 1 次；撞车给 XP/树果 |

- 三通道统一落库：同种唯一校验 → 队空入队 / 队满入仓 → 图鉴点亮。
- 已有该 dex：直购不可买；蛋/签约走撞车规则。
- 传说 dex 不进入直购；普通蛋 1% / 高级蛋 3% 独立概率；联赛冠军或四天王可触发当期 2 只传说自选（共享池）。

## 11. 存档字段

```js
save = {
  version, createdAt, coach, coins,
  team: [], box: [], mons: {}, dex: {},
  bag: { berryNormal, berryPremium, ... },
  shop: { date, slots, soldFlags },
  eggs: { unlockedSlots, slots: [], stock: [] },
  assign: {},                 // 个体 id -> 实际位置
  journey: { season: { ... } },
  stats: { w, l }
}
```

- 不再有 `franchise` / `trade` / `freeAgency` / `draft` 字段。
- 旧档迁移：缺失字段补默认值；`assign` 按 `mon.pos` 初始化。

## 12. 验收清单

- [ ] 篮球币永远 ≥0；购买前校验；购买失败回滚。
- [ ] 退出/失败不产币（除每天前 3 次安慰奖）。
- [ ] 传说 dex 不出现在每日商店货架；普通蛋 1% / 高级蛋 3% 独立判定；四天王首通赛季只能领一次。
- [ ] 蛋的 dex 在购买时定死；离线照孵。
- [ ] 树果可留存；Lv99 不可使用；仓库可喂。
- [ ] 图鉴点亮不给币；里程碑/成就发放一次。
- [ ] 战胜签约每对手每天限 1 次；撞车不退币。
- [ ] 旧档迁移不丢 `coins` / `team` / `box` / `mons` / `dex`。
