# 08 教学与开局（跨层 · 引导流程 L2 + 表现 L1）

> 新玩家第一次 10 分钟的体验设计。

## 教程（Tutorial）

- 触发：首次选完初始伙伴后自动开始
- 内容：约 2 分钟的 8 段练习，覆盖移动、传球、上篮、扣篮、空接、投篮、抢断、盖帽
- 专用配置（tutorialConfig）：
  - 固定训练阵容（妙蛙种子 / 小火龙 / 杰尼龟 / 皮卡丘 / 伊布），不读写生涯队伍
  - 每节 90 秒、难度 rookie、关闭体力、固定随机种子 20261031、练习模式
- 表现：顶部教练条（提示 + 跳过本项/退出）、一次按键说明、单段完成即自动进入下一段
- 教程结束固定赠送杰尼龟 + 腕力（本命重复时备用伙伴补位），并引导去商店买两只新伙伴、把他们拖进首发
- 「跳过本项」只跳过当前练习；「跳过教程 / 退出」和开始界面的「跳过教程，直接领首发」一样，**直接视为完成**：补齐全首发 + 100 币，并标记 `newbie.tutorialDone`，新手之路直接进入商店步骤；新手之路面板第 1 步也提供「跳过教程，直接领首发」，避免玩家卡在教程

## 训练内容

| # | 练习 | 限时 | 内容 |
| --- | --- | ---: | --- |
| 1 | 移动 Movement | 10 秒 | 拖动摇杆跑向篮筐，推满冲刺 |
| 2 | 传球 Pass | 10 秒 | 按传球交给队友 |
| 3 | 上篮 Layup | 12 秒 | 靠近篮筐按投篮上篮 |
| 4 | 扣篮 Dunk | 12 秒 | 推满摇杆冲进禁区，再按投篮扣篮 |
| 5 | 空接 Alley-oop | 15 秒 | 队友切到篮下时按传球，球直接抛向篮筐 |
| 6 | 投篮 Jump Shot | 15 秒 | 按住投篮，蓄力条进入完美区时松开 |
| 7 | 抢断 Steal | 15 秒 | 贴近持球人按抢断（教程内不会误触发撞击） |
| 8 | 盖帽 Block | 18 秒 | 对手出手时按投篮起跳封盖 |

- 不再逐段弹出结果卡；动作成功后停留约 1.4 秒，让传球/投篮/扣篮动画播完再进入下一段（超时则 0.5 秒后进入下一段）
- 扣篮 / 空接 / 盖帽使用教程专用站位：扣篮直接把人放到禁区，空接固定传给篮下队友，盖帽让对手在 6 秒内出手
- 全部完成后进入「准备开打」页，展示新伙伴与首发阵容

## 开局引导链（教程 → 买精灵 → 队伍配置 → 第一场）

```
选初始伙伴 → 约 2 分钟教程（8 个动作） → 固定赠送杰尼龟 + 腕力
→ 商店买 2 只精灵 → 把新伙伴拖进首发 → 第一场比赛
```

- 新手之路为 4 步：完成教程 → 商店买两只 → 把新伙伴拖进首发 → 开始第一场比赛
- 教程固定送 **杰尼龟 + 腕力**；若本命已占其中一只，用备用伙伴补位，保证仍送两只
- 要求买 **2 只**低价精灵（新手货架 OVR<70 特惠 150 币；教程补给 200 + 开局 100，共 300 币刚好够买两只）
- 队伍页会把刚买的新伙伴标「新」并给出提示；把它拖进任意首发槽即完成配置
- 完成前从主页点「开始比赛」会先打开新手之路，避免跳过商店和队伍操作
- **训练定位=新手教程**：不是独立模式，不承载长线目标；后续操作不熟可在「导引 → 操作教程」重看（约 2 分钟：移动 / 传球 / 上篮 / 扣篮 / 空接 / 投篮 / 抢断 / 盖帽）
- **五位置选伙伴定位=开局建队**：先选位置，再获得该位置对应的 Lv1 伙伴
- **快速比赛定位=娱乐沙盒**：无成长压力的自由玩法，老玩家随手一局；入口在主页九宫格，不接入构筑。开打前临时选秀 5 人（控卫/分卫/小前/大前/中锋各 1 只），对手用原版道馆阵容；可自由选 8 道馆 / 四天王与三档难度；2 节 × 2 分钟短局，不计战绩、不发奖励、不消耗次数，选秀阵容不写入存档

### 五位置初始伙伴

| 位置 | 伙伴 |
| --- | --- |
| PG | 杰尼龟 |
| SG | 小火龙 |
| SF | 妙蛙种子 |
| PF | 腕力 |
| C | 小拳石 |

- 初始伙伴 Lv1 零 bonus，推荐位置直接设为所选位置，避免越位惩罚。
- 位置只决定开局槽位和培养方向，之后仍可在队伍页拖动调整；进化时按新种族更新推荐位置。
- 开局卡不显示属性标签，位置统一用字母；卡面显示该位置下的初始 OVR。
- “组织/投射”等定位文案没有机制作用，已移除，避免增加理解负担。
- 属性克制等完整规则说明已移到「导引 → 说明」。

## 局外新手引导（v3，2026-11-12）

- 触发：新存档首次进入主页；状态存于 `save.guide = { v: 1, step, done }`，完成后同时写 `save.onboarded = true`。
- 范围：只讲局外流程，不进入比赛内操作。走完新手之路（操作教程）的玩家，首场正式比赛不再重复弹「30 秒新手引导」。
- 6 步（全部在主页）：
  1. 资源与目标（顶栏：篮球币来源与用途、徽章来源）
  2. 队伍与位置（10 只上限、前 5 首发、八项能力与推荐位置）
  3. 每日商店（精灵 / 蛋 / 树果、孵化时长与传说概率）
  4. 孵蛋与成长（槽位、购买/广告扩容、树果经验与训练点）
  5. 每日挑战（每日阵容、首胜与任务金币）
  6. 开始比赛（指向「导引 → 说明」查看赛制与结算）
- 交互：全部用「下一步」推进；可随时跳过。
- 主页顶栏新增「导引」按钮，任何存档都可随时重看，不再只能等首次进入。
- 指引浮层不拦截页面点击；高亮目标自动滚动到视口，卡牌自动放在目标上方或下方。
- 中途离开保留进度；回主页显示「继续指引」。导航到其他页面时浮层自动清理。
- 复古体育主题下，指引卡牌同步使用报纸米色底、墨线边框和绿色主按钮。

## 新手友好机制

- 获取金币：主页金币 `+` →「获取金币」，只保留看广告 +200 币（每日 10 次）；原新手任务已于 S37 删除。
- rookie/pro 难度自带移动辅助（assist）与橡皮筋追分（catchup）
- 自动换人默认开启，不用管轮换
- 开局五选一没有超时压力；选完直接进入第一馆
- **首场 30 秒新手引导**：仅对没走过操作教程的新存档触发，显示「移动 → 投篮 → 传球/必杀」三段非阻塞提示，每 10 秒切换，可跳过；只出现一次，不打断比赛；新手之路已教过则不重复
- 难度随时可改（快速比赛赛前界面）
