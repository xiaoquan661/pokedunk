# 15 长线运营设计研究（L3 · 动作游戏运营方法论）

> 目的：回答"动作类游戏怎么做长线运营"，并映射到宝可灌篮找差距。
> 来源：长线留存设计（D1/D7/D30）、中等硬核核心循环（双重循环）、Daily Run 设计规范（GameDeveloper）、剑与远征/洛克王国（养成验证/收集驱动）、我功夫特牛（Roguelike+RPG）、NBA 2K Playgrounds 2（反面警示）。

## 一、动作游戏长线的三条铁律

1. **手感是根基，长线是放大器**——NBA 2K Playgrounds 2 的教训：街机手感做对了，但被付费墙埋葬；我功夫特牛的优点恰恰是"普攻分解动作+音效特效"的打击感。我们的对应：比赛引擎核心手感零改动是红线，一切运营钩子只能放大它，不能打断它。
2. **动作游戏的长线=把"一次精彩操作"变成可重复追求的目标**——战力榜测的是配置不是操作，所以生硬。运营设计必须制造"我这一局打得漂亮"的出口（分数、层数、回放、记录）。
3. **广告与内购不卡核心体验**——激励视频只在"可选加签"处出现，保持。

## 二、双重循环架构（中等硬核核心循环）

每个核心循环应包含两个可分离的回合层 + 一层元游戏：

| 层 | 长度 | 玩家随时可做 | 我们的对应 |
| --- | --- | --- | --- |
| 短循环 | 30 秒~3 分钟 | 一节比赛、一次每日挑战局、一次签约/练习 | 比赛（1~5 分钟/节）✓；每日挑战 ✗ |
| 长循环 | 半天~一周 | 赛季推进、养成批次、挑战目标 | 赛季 8 馆 × 4 小关 + 四天王 = 33 场，可模拟速通 ✓ |
| 元游戏 | 持续 | 收集图鉴、进化树、成就、排行榜 | 291 图鉴/成就/战力榜 ✓ |

**关键判定**：玩家"下一个 30 秒"永远有事可做，且短循环产出直接喂养长循环。我们目前短循环只有"多打一场比赛"一种，每日挑战是缺失的第三入口。

## 三、留存三段式（D1 / D7 / D30）

- **D1（第一晚挂念点）**：首日结束必须留一个"未完成"——下次回来做什么要清清楚楚（领取建造结果/解锁新角色/挑战下一章）。
  - 我们：第 1 关通关后停在"第 2 关 · 华蓝道馆"赛前夜 ✓（关卡横幅已明示下一关）。**缺口**：没有"明日预告"式情绪钩子（如"小霞的水系队伍在等你——带上电属性"）。
- **D7（习惯形成）**：日常循环短而有意义、围绕核心玩法；一周内节奏化展开：D2 强化 → D3 活动 → D4 社交 → D5 挑战 → D7 阶段总结。
  - 我们：周签约是习惯锚 ✓；但**没有每日节奏**（每天都一样）。每日挑战+轮换 modifier 就是"今天的玩法不一样"。
- **D30（长期目标可见但不近）**：角色收集、阵容构筑、赛季排名、装备毕业、外观收藏——可见、永不"太近"。
  - 我们：291 图鉴、进化树、战力榜 ✓；**缺口**：战力榜无赛季语义（单调递增，头部固化）；传奇挑战（极限出口）未做。

## 四、每日挑战设计规范（Daily Run 24 小时票）

同类实践：Caveblazers（共享 seed+共享 modifier）、Dead Cells（无限尝试、当日最高分、仅 live 局计分）、OlliOlli（练习无限次 + "do it for real" 单次正式尝试）。

**我们的实现条件（关键优势）**：比赛引擎本来就吃 seed（`zs(s, …)` 的 RNG 由 `a.seed` 派生）——**用日期字符串做 seed，全平台当天同一局天然可复现**，不需要新增 RNG 设施。

建议规格（V2~V3 落地时遵循）：

| 设计点 | 建议 | 理由 |
| --- | --- | --- |
| seed | `pokejam-daily-YYYY-MM-DD` 派生 | 同一天全平台可比；排行榜才有意义 |
| 尝试次数 | 无限次尝试、当日最高分 | Dead Cells 模式：对休闲友好；单次 live 模式（OlliOlli）留给 hardcore 变体 |
| 阵容 | 当日限定规则（如"只能用草属性""全员 Lv3"） | 制造每日决策，逼玩家动用冷门精灵 |
| modifier | 当日祝福/诅咒各一（如"三分 ×2""体力减半"） | Caveblazers 验证的"体验旅游"感 |
| 分数口径 | 单场得分 + 风格分（扣篮/必杀/压哨加成） | 让"怎么打"影响名次，不只是"赢没赢" |
| 时长 | 单节 3 分钟 ×4 | 与赛季一致，符合验收表"单局 ≤30 分钟" |
| 防刷边界 | 本地内存可改=休闲级接受（GDD 既有决策） | 不为防刷牺牲体验 |

**运营意义**：每天"这一局换了什么招"就是打开理由；同 seed 让评论区出现"这关用什么阵容"的社区讨论（GameDeveloper 指出的 puzzle 效应）。

## 五、养成验证结构（剑与远征 / 洛克王国）

- **PVE 关卡=养成验证点**：我们已有（道馆=验证点、AI 补强=压力源）。
- **卡关→资源缺口引导**：剑与远征用卡关提示"该强化了"。我们对应：卡关界面可提示当前瓶颈（"对面 C 97 OVR，你的内线吃紧"）——低成本的引导强化。
- **收集驱动的完整性**（洛克王国）：每只精灵的独立故事/羁绊增强收集欲。我们：图鉴已有简介；进化播报已有。**可选**：图鉴页加"本作战绩"（该精灵为你出场的胜率/场均）——把收集与战斗记忆绑定。
- **任务系统的可预期性**："做任务就能变强"的密集引导。我们：成就偏长期，**缺每日任务层**——若做每日挑战，配 2~3 个当日小任务（赢 1 场/扣篮 3 次）即可形成"任务→局→结算→领奖"短循环。

## 六、活动节奏（运营日历雏形）

| 频率 | 内容 | 依赖 |
| --- | --- | --- |
| 每日 | 每日挑战局 + 2~3 个当日任务 + modifier 轮换 | V3 每日挑战（建议提前） |
| 每周 | 周签约刷新（已有）+ 每周传奇 boss 轮换 | V2 传奇挑战 |
| 每季（33 场） | 赛季结算：战力榜归档 + 荣誉页 + 新季更强 | 赛季语义（低成本） |
| 里程碑 | 版本更新公告（运营验收表要求） | 主菜单小字 |

| # | 缺口 | 对应铁律 | 成本 | 优先级建议 |
| --- | --- | --- | --- | --- |

## 八、与既有规划的关系

- GDD v2.3 的 V3"每日挑战+每日分数榜"**建议提前到 V2 首位**（本研究的最大结论）；
- 传奇挑战保持 V2，形态建议"轮换 boss"先行（成本低于无尽塔，数据好再加深）；
- 战力榜不推翻，补赛季语义即可（既有用户决策：排行榜=球队战力，尊重）。

## 九、模式分类定案（2026-11-05 用户讨论收敛）

**关键认知：训练师之旅（8 馆 × 4 小关 + 四天王）就是跑步机型无尽模式**——微观波浪（每季重置关卡/徽章）、宏观单调上升（每赛季 +2 战力，强度跟着玩家走）。这是收集养成游戏最成熟的留存引擎，维持现状不改。

**但跑步机有天花板**：球员 Lv99 属性封顶，AI 同样会到 99。毕业日终会到来——全队 99 后每季变成完全相同的重播。**毕业后内容**是真正的设计空洞，各系统的正确分工：

| 系统 | 毕业前的作用 | 毕业后的作用 |
| --- | --- | --- |
| 训练师之旅跑步机 | 主循环（养成压力） | 日常维持（同强度重播） |
| 每日挑战 | 操作流舞台（战力未满也能靠操作上榜） | **主要竞技场**（数值拉平后操作是唯一差异） |
| 传奇挑战 = **毕业考** | 提前撞墙（boost +6~8，99 级前几乎不可能赢） | 真正的墙（数值全满后的最后一战） |
| 战力榜赛季归档 | 赛季流动性 | 毕业后仍在变的荣誉系统 |

**传奇挑战定位修正**：不做无尽塔（无尽职能已被训练师之旅占据）。定位=通关四天王后的**隐藏毕业考**——每季轮换一只传奇明星队（如 S1 超梦、S2 阿尔宙斯），boost +6~+8，赢了拿传奇徽章（图鉴/荣誉向，无数值奖励防通胀），输了随时再来（与道馆同规则）。它是内容，不是竞技，不上榜。

**三榜三测分工**：训练师之旅测养成（战力榜）／每日挑战测操作（每日分数榜）／传奇挑战测荣誉（图鉴收录，不上榜）。

**实施排序（本会话待办）**：① 每日挑战+每日分数榜（seed=日期，引擎天然支持）② 战力榜赛季归档 ③ 传奇挑战毕业考 ④ 赛季中心/其余。当前阶段先落文档与设计，用户确认后再实施。

## 十、每日挑战实施定案（v2.5，2026-11-11）

> 落地文件：`js/journey/daily.js`（逻辑）、`js/ui/daily.js`（面板）、`app.js`（开球/结算接线）。

| 设计点 | 实现 |
| --- | --- |
| 入口 | 主页「每日挑战」通栏按钮（今日规则 + 当日最高分），打开弹窗卡片 |
| seed | `FNV(pokedunk-daily-YYYY-MM-DD)`，当天全平台对手与 AI 一致 |
| modifier | 7 条按日期轮换，双方同享：三分雨(投篮+6) / 铁壁防线(防守·盖帽+6) / 快攻风暴(速度+6·传球+3) / 篮板大战(篮板+8·终结+3) / 内线霸权(终结+6·盖帽+4) / 抢断之夜(防守+5·速度+4) / 全明星(全属性+3) |
| 对手 | 与 modifier 同系的联队，战力 = 我方 `teamPower + 2`（夹 45~97），位置覆盖 PG/SG/SF/PF/C；面板展示对手首发 5 人（头像/位置/属性/OVR） |
| 赛制 | 3 分钟 × 4 节，无限次尝试；**仅限手动比赛，不提供一键模拟** |
| 挑战分 | 我方得分 + 扣篮×3 + 三分×2 + 抢断×2 + 盖帽×2 + 胜利 10；只记当日最高 |
| 奖励 | 每日首胜 +100 币；3 个当日任务：完成 1 场 +30 / 赢 1 场 +60 / 单场扣篮 2 次 +40 |
| 边界 | 不推进赛季、不计生涯战绩、不发 XP/不触发签约——防止与训练师之旅互相刷取 |
| 存档 | `save.daily = { date, plays, wins, best, bestDunks, firstWin, missions, history[7] }`；跨日懒重置 |
| 榜单 | 当前仅本地记录（历史 7 天）；跨玩家分数榜待排行榜基建，不在本地伪造 |

**图鉴里程碑（v2.5）**：10/30/50/100/150/200/291 档，奖励见 docs/04 §9；图鉴页进度条 + 档位领取，存档 `save.milestones`。
