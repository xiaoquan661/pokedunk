## 1. 设计目标与原则

### 目标

1. 主页永远能回答“下一步做什么”。
2. 每次投入（赢/输、比赛/日常/挂机）都推进一个长期目标。
3. 收集是钥匙，不只是记分板。
4. 强化保持四条清晰轴：等级、训练、进化、道具。
5. 不为了“系统多”而加系统。

### 原则

- **保留现有系统**：除本文件明确修改的项外，现有玩法、UI、存档字段不动。
- **一条主线**：地区 → 按顺序 8 馆 → 8 徽章 → 四天王 → 地区冠军 → 下一地区。**不再有 9 队联赛、积分榜和季后赛。**
- **一个地区 20 级**：关都 1–20、城都 21–40、丰缘 41–60（待数据）；后续地区按 +20 追加。
- **不新增货币**：篮球币、树果、训练点、孵蛋道具、进化道具。
- **同种唯一**：异色不产生重复个体；已拥有同种时转为异色皮肤。
- **广告只加速**：不卖徽章、图鉴、钥匙、等级上限。

### 3.6 道馆路线（S69/S70）

常规赛馆主不是直接开打，先清一条 5 关路线：

1. **野生宝可梦 · 前段**（1v1）：打赢可收服，给经验，不消耗每日野球次数。
2. **路线训练家**（5v5）：小人物球队，给金币 + 首发经验。
3. **补给点**：领取 1 个普通树果 + 20 篮球币，不战斗。
4. **野生宝可梦 · 深处**（1v1）：同前段，路线加深。
5. **馆主**（5v5）：走现有联赛结算，胜利给徽章。

前四关不推进赛季；馆主战胜利才推进赛程/徽章。路线进度存 `journey.route = { key, step }`，失败可重试；换馆/换赛季自动重置。主线页显示“路线 x/5”，准备入口仍可用。

路线的 8 条关都主题（常磐森林、月见山、地鼠洞、岩山隧道、宝可梦塔、西尔佛公司、宝可梦屋、冠军之路）写在 `ROUTE_META`；训练家名字/补给点名称按主题替换，可见文案与对手阵容（小人物 5v5，战力比馆主低 12）保持现有战斗核心不变。

**与《口袋冒险》镜像的对照**：镜像 STORY 每章由 `gift / route / heal / find / gym` 节点组成，`route` 节点带 `wild` 与 `trainers` 计数；关都 14 章 = 8 馆 + 冠军之路 + 四天王 4 场 + 冠军。前几章 wild 2–4、trainers 0–2，后段章 wild 8–25、trainers 4–14。本作把一章压缩成 5 个节点（两场野生 + 一场训练家 + 补给 + 馆主），保留“先清路线再打馆主”的推进结构，但不照搬长线计数器：篮球 5v5 单场时间更长，压缩到 5 节点以控制单馆节奏。镜像的 `gift`（送初始精灵）、`heal`（回复）、`find`（拾取）分别由现有御三家开局、树果/孵蛋、补给点承接。

- 城都：新增 8 馆 + 四天王（使用 152–251 图鉴内精灵）。

## 4. 图鉴钥匙

### 4.1 属性钥匙

- 每个属性集齐 8 种 → 解锁该属性的“神兽/明星球员”追踪遭遇。
- 现有属性徽章从“纯展示”升级为“钥匙进度”：点亮徽章即获得钥匙。
- 钥匙只给一次遭遇资格，不直接送精灵；打赢招募战才加入。

### 4.2 篇章钥匙

- 每个地区篇章 100% → 解锁该地区神兽（关都三鸟、城都三兽；丰缘三柱待数据）。
- 现有 50%/100% 纪念章保留；100% 完成勋章同时作为钥匙凭证。

### 4.3 钥匙遭遇规则

- 一次性特殊野球场/传说战，推荐等级 = 当前地区上限。
- 招募条件：赢 8 分以上。
- 失败可次日重试；不消耗广告次数。
- 已拥有同种时，不再进入钥匙池。

### 4.4 图鉴追踪（S83 已删除）

- S54 的追踪功能已整体移除：不再有追踪目标、追踪按钮、野球场 45% / 商店 65% / 签约保底。
- 图鉴与冒险进度只展示真实可获得内容；未结缘精灵的获取途径仍写在详情页。

### 4.5 联盟邀请赛（S89）

- 解锁：当前地区集齐 8 枚徽章后，冒险进度页出现「联盟邀请赛」入口。
- 独立于主线：不改变徽章、等级上限、四天王、地区冠军和主线存档。
- 参赛：玩家队 + 8 位馆主，共 9 队。
- 赛制：9 轮单循环，每轮 4 场 + 1 队轮空；每队 8 场 + 1 轮轮空。胜 3 分，同分看净胜分、相互战绩。
- 季后赛：前 4 名进半决赛（1v4、2v3），胜者进入总决赛。
- 每场可选手动、观战或模拟；提供「模拟本轮」，其他球队比赛同步模拟。
- 每场固定产出（S91，鼓励反复刷级）：胜 40 经验 + 60 币，负 20 经验 + 20 币；经验发给全体首发。
- 奖励：首通冠军获得联赛奖杯 + 2300 币 + 高级树果 ×2 + 孵蛋加速券 ×1；重复参赛按冠军 800 / 亚军 500 / 四强 300 / 常规赛 150 发币。每场固定产出与名次奖励独立结算，可反复参赛。
- 存档：`journey.league`，保存赛程、战况、积分、季后赛与奖杯；可随时退出后继续。

## 5. 异色与游走神兽

### 5.1 异色（闪光）

- 获取：野球场打赢收服时、孵蛋时各做一次异色判定，基础 1/512。
- 不新增“异色狩猎”模式，不设每日 200 次。
- 已拥有同种时：异色结果转为该精灵的**异色皮肤**，可在详情页切换；不产生重复个体。
- 未拥有同种时：正常加入，个体带 `shiny` 标记。
- 图鉴新增“异色”页签；异色不改数值、不改技能。

### 5.2 游走神兽

- 每 2–4 小时出现一个 30 分钟窗口；主页显示倒计时。
- 每个窗口 1 次遭遇；只从“未拥有的地区神兽”中抽取。
- 招募条件：赢 8 分以上。
- 错过窗口进入下一次，不逼在线；不可用广告刷新。
- 已拥有同种时不再进入游走池。

## 6. 昼夜、天气与挂机

### 6.1 昼夜

- 现实时间 6:00–18:00 为白天，其余为夜晚。
- 昼夜分池：现有路线池保留，叠加时段权重：
  - 白天：一般/草/虫权重提高；
  - 夜晚：幽灵/恶/超能权重提高；
  - 水域/洞窟路线保留自身属性池。

### 6.2 天气

- 每日天气由“日期 + 地区”决定；主页显示。
- 当天一个属性在野球场获得 +10% 出现权重/强度修正（只影响野球场，不影响赛季/排位）。
- 蛋壳花纹随天气变化（纯表现，不影响孵化时间）。

### 6.3 挂机

- 草地：保留现有离线 XP。
- 新增“夜间球探/特训”：
  - 8 小时上限；
  - 产出：树果、篮球币、低概率进化道具；
  - 不产 XP，避免与草地重复；
  - 收取后进入背包/材料。
- 不做无限挂机，不做离线战斗。

## 14. 风险与待定

1. **等级上限与现有平衡**：当前 1 徽章 Lv6；需用真实等级分布校准 10/15/20 三档与馆主 OVR。
2. **城都馆主阵容**：需要新内容；在完成前，第 2 赛季不能只复用关都馆主。丰缘需先补 121 只精灵数据，才能做 8 馆。
3. **异色与同种唯一**：必须走“异色皮肤”方案，不能产生重复个体。
4. **游走神兽经济**：只从“未拥有”池抽取，避免重复返还过重。
5. **挂机通胀**：球探 8 小时上限，产出低于主动玩法。
6. **系统数量**：本版已砍掉 7 个系统；实施时不再临时加系统。
