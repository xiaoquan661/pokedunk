# 09 赛季与关卡（L2 · 8 馆 × 4 小关 + 四天王）

> v2.4（2026-11-11）新建。替代 GDD S8 旧“9 关 + 巡回赛”描述；旧 `story.js` 的关卡推进只保留“胜利推进 / 失败重试 / 夺冠结算”的行为思想，具体结构以本文为准。
> 赛季 = 8 个道馆 × 4 个小关 + 四天王 = **33 场**；**全部可一键模拟**。
> 构筑与战力口径见 `docs/02-数值系统.md` 附、`docs/03-构筑与选秀.md`。

## 1. 赛季总结构

```text
赛季
├─ 大关 1~8：8 个道馆
│   ├─ 小关 1：同系新秀队
│   ├─ 小关 2：同系主力队
│   ├─ 小关 3：同系王牌队
│   └─ 小关 4：小决赛 · 原版馆主队
└─ 终关：四天王联队
```

| 层级 | 内容 | 场次 |
| --- | --- | --- |
| 大关 | 一个道馆/场馆 | 8 |
| 小关 | 场馆内 3 常规 + 1 小决赛 | 每馆 4 |
| 终关 | 四天王联队 | 1 |
| 合计 | | **33** |

- 不再有“8 强季后赛”额外阶段；8 个道馆本身就是 8 个大关，四天王就是总决赛。
- 一个赛季 33 场；因为全部可模拟，玩家可以速通，也可以逐场手打。

## 3. 每馆四小关

| 小关 | 队伍 | 来源 | 目标战力 | 奖励 |
| --- | --- | --- | --- | --- |
| 1-1 新秀赛 | 同系新秀队 | 同系池，排除馆主 5 只 | 馆主 -6 | 币 + XP |
| 1-2 主力赛 | 同系主力队 | 同系池，不同组合 | 馆主 -4 | 币 + XP |
| 1-3 王牌赛 | 同系王牌队 | 同系池，较强组合 | 馆主 -2 | 币 + XP |
| 1-4 小决赛 | **原版馆主队** | 原版 `GYM_ROSTERS` | 原版馆主强度 | 徽章 + 大奖励 |

- 馆主队保持唯一、最强；3 支常规队是“同门挑战者”，不是馆主队的复制品。
- 3 场常规赛每赢 1 场，小决赛全队有效属性 +1%，最多 +3%；3-0 额外 +10% 金币。
- 每个小关可重试；失败计入战绩；小决赛输了可重打小决赛，不用重打前 3 场。

## 4. 同系队伍生成

### 4.1 选池

1. 主题系别：每个馆一个主系（岩石/水/电/草/毒/超能/火/地面）。
2. 优先取 `types[0]` 同系；不足 5 只时加入第二属性同系。
3. 仍不足 5 只时，用中立/相邻系补位。
4. 3 支常规队尽量排除馆主 5 只；池子太小才允许少量重叠，但不能整套重复。
5. 同一队内不重复 dex；不同队之间池子够就不重复。

### 4.2 队伍结构

- 每队 5 人，尽量覆盖 PG/SG/SF/PF/C；缺位置用补位精灵，不硬凑。
- 我方队伍不足 5 人时仍可开球：只使用队伍内真实精灵，不从仓库/训练生补位；赛前页不额外提示人数，直接开赛。
- 三种风格：
  - 防守型：高 def/blk/reb。
  - 进攻型：高 sht/ins/spd。
  - 均衡型：位置覆盖优先，八维均衡。
- 队名只是包装，可按场馆主题命名（岩壁队/碎石队/巨岩队等）。

### 4.3 馆主队

- 继续使用原版 `pickGymRoster` / `GYM_ROSTERS`，不改阵容。
- 馆主队不吃“同系排除”规则，它就是该馆的顶点。

## 5. 目标战力

```text
teamPower = 队伍 10 人里前 5 高的 monPower 平均值
leaderPower = 原版馆主队有效战力 + (赛季数 - 1) × 2
常规 1 = leaderPower - 6
常规 2 = leaderPower - 4
常规 3 = leaderPower - 2
小决赛 = leaderPower
四天王 = 原版四天王有效战力 + (赛季数 - 1) × 2
```

- `monPower` 含等级、训练、道具、位置适配、羁绊。
- 常规赛可软保底：`target = min(原版目标, teamPower + 10)`，防止越级墙。
- 小决赛/四天王保留原版强度，不软保底；打不过就练或重试。
- 同一小关连败 3 次，下一场 `target -3`，赢了恢复。
- 难度档位只控制 AI 行为；数值差距由 `boost` 补，不重复改数值。

## 6. 一键模拟

### 6.1 范围

- **33 场全部可模拟**：常规赛、馆主战、四天王都可以。
- 不再有“必须手打”的关卡。

### 6.2 结果

- 使用引擎 `simulateFullMatch`，按双方有效战力 + seed 出比分。
- **观战**：另提供“双方 AI 自动进行完整比赛”的观战入口（不进入无头模拟，实时渲染球场）；无触屏操作，结果按模拟口径（80% 奖励、无首通）结算并正常推进关卡。
- seed 由 `赛季 / 场馆 / 小关 / 尝试次数` 派生，保证同一次尝试可复现。
- 赛前显示预计胜率（仅展示，按战力差估算）：
  ```text
  p = clamp(0.5 + (teamPower - targetPower) × 0.03, 0.05, 0.95)
  ```
- 模拟失败计入战绩；可重试，也可以改手动打。

### 6.3 奖励

| 结果 | XP | 篮球币 | 首通奖励 |
| --- | --- | --- | --- |
| 模拟胜利 | 80% | 80% | 无 |
| 手动胜利 | 100% | 100% | 有 |
| 模拟失败 | 0 | 0 | 无 |
| 手动失败 | 少量 XP | 0 | 无 |
| 中途退出 | 0 | 0 | 无 |

- 3-0 场馆金币加成：手动 +10%，模拟 +5%。
- 模拟胜利同样推进关卡、拿徽章、进四天王。
- 首通奖励只给手动胜利，避免“全模拟跳过游戏还拿满奖励”。

## 7. 奖励与赛季重置

### 7.1 单场奖励

| 关卡 | XP | 篮球币 |
| --- | --- | --- |
| 常规赛胜 | 40% | 40% |
| 小决赛胜 | 100% | 150% + 徽章 |
| 四天王胜 | 200% | 300% + 奖杯 |

- 重复通关：100% → 50% → 25% → 10%（按赛季内该小关计算）。
- 首通奖励：手动胜利额外 +50% 该关基础奖励。

### 7.2 赛季冠军

- 四天王胜利：奖杯、300 币、1 个道具、图鉴里程碑、历史记录、赛季 MVP。
- **冠军传说自选**：每赛季首通四天王解锁，从当期 3 只传说中选 1 只，必得；每赛季轮换 3 只。未领取保留在赛季页；重复传说折算 200 币。
- 冠军后进入下一赛季：
  - 重置：8 馆进度、小关记录、徽章。
  - 保留：等级、训练、道具、羁绊、图鉴、金币。
  - 所有场馆 `+2` 战力，循环变强。

### 7.3 防刷

- 退出 = 判负，0 币、0 XP。
- 失败安慰奖每天前 3 次 20%，之后 0。
- 模拟胜利 80% 奖励、无首通；重复通关递减。
- 不做“每周 AI 悄悄成长”；赛季 +2 写进公式，透明。

## 8. 存档字段

```js
journey.season = {
  no: 1,
  phase: "venue" | "final" | "done",
  venue: 0..7,          // 当前大关
  small: 0..3,          // 当前小关
  results: [            // 每小关结果
    { venue, small, win, myScore, oppScore, sim, attempt }
  ],
  badges: [],           // 本赛季徽章
  champion: false,
  history: []           // 赛季冠军/MVP/战绩
}
journey.legend = {
  claimed: [],          // 已领取冠军传说的赛季号
  pending: [{ season, choices: [dex, dex, dex] }]  // 待领取的 3 选 1
}
```

- 每打完一个小关自动存档，33 场中途退出不丢进度。
- `save.assign` 单独存首发实际位置；赛季重置不清 `assign`。

## 9. UI

- 赛季页竖排 8 个道馆，不再显示“大关”层级；道馆名前的数字只是序号，每个道馆展开 4 个小关：

```text
1 深灰道馆
  新秀赛   ✓
  主力赛   ✓
  王牌赛   ● 当前
  小决赛   馆主·小刚
2 华蓝道馆   🔒
...
四天王联队   🔒
```

- 当前关高亮；下一关锁定；已通关显示比分/是否模拟。
- **赛程折叠**：已完成馆默认收起（点标题展开看比分），未解锁馆只保留一行，仅当前馆展开 4 小关。
- 赛程页显示：`当前关卡 / 推荐战力 / 你的战力 / 预计胜率`。右上角徽章计数可点击，打开道馆徽章详情（8 枚徽章、获得状态与本赛季比分）；主页徽章条同样可点击。
- **出战 → 赛前对阵页**：展示双方战力、对手首发、我方首发与替补、预计胜率；卡片右上角显示 OVR（首发按当前槽位计算，替补按主位置计算）。该页**只读，不可调整阵容**，点「继续」开球，「返回」回主页。
- 观战直接从赛程页进入，双方 AI 自动比赛。
- 按钮：`出战` / `观战` / `一键模拟`。
- 赛后：结果、奖励、下一关；模拟/观战失败时提供“重来 / 手动打”。首通道馆小决赛时播放徽章获得动画。
