# 17 主线与局外系统设计（S55 设计稿）

> 状态：**探索稿，部分系统已舍弃**（2026-11-26）
> 现行定案见 `docs/18-GDD-主线与收集.md`：性格/宝石/交换/团体战/培育屋/研究度等已在该版舍弃；9 队联赛/季后赛也已在 S72–S73 删除。
> 目标：把“只有比赛”的游戏改成“比赛是主线的一部分，收集与养成是长期目标”。
> 参考：虎扑《口袋冒险》（收集即钥匙、时间窗、挂机、交换、广告只卖重roll）与 PokéBonk（失败也有产出、永久研究所、每日固定规则、收集改变构筑）。

---

## 0. 问题与目标

### 现状

- 赛季是唯一强目标，但只吃“当前战力”；
- 图鉴、排位、每日、野球、商店、孵蛋、草地各自结算，最终都发篮球币；
- 篮球币只能回到商店/训练，没有账号级承接；
- 玩家打完一场，不知道“下一件必须做的事”是什么。

### 目标

1. 任何时候，主页都能回答“我现在该干什么”。
2. 任何行为（赢/输、比赛/日常/挂机）都推进一个长期目标。
3. 收集不是记分板，而是解锁新内容的钥匙。
4. 强化不只是数值，有性格、进化、研究度三条可见路径。
5. 广告只卖“重roll / 加速 / 额外次数”，不卖徽章、图鉴、神兽。

### 非目标

- 不做体力条；
- 不把比赛改成全自动；
- 不在本轮补第四、第五世代图鉴数据；
- 不做实时玩家交易（依赖后端，后置）。

---

## 1. 设计原则

1. **一条主线**：地区 → 8 道馆徽章 → 四天王 → 冠军 → 下一地区。
2. **图鉴是钥匙**：集齐属性/篇章，解锁神兽或明星球员，而不是只发币。
3. **失败也产出**：输球仍给研究度/经验，保证每次投入都推进长期进度。
4. **时间生产**：蛋、挖矿、团体战、游走神兽各自有次数/时间窗，制造回访。
5. **广告只加速**：不卖钥匙，不卖等级上限。
6. **同种唯一**：孵蛋/交换只能补未拥有图鉴或换性格，不刷重复个体。
7. **不新增货币**：优先复用篮球币、树果、训练点、孵蛋道具；如确需新增，只加一种“研究点”，且本设计先不引入。

## 2. 系统总览

```
┌──────────────── 主线层 ────────────────┐
│ 地区 → 8 道馆徽章 → 四天王 → 冠军 → 下一地区 │
└───────────────┬────────────────────────┘
                │ 徽章 = 等级上限 + 设施解锁
┌───────────────▼────────────────────────┐
│ 收集层：捕捉 / 孵蛋 / 培育屋 / 交换 / 游走 / 闪光 │
│        → 图鉴 → 属性钥匙 / 篇章钥匙 → 神兽      │
└───────────────┬────────────────────────┘
                │ 图鉴等级 = 账号成长
┌───────────────▼────────────────────────┐
│ 养成层：等级 / 性格 / 进化 / 研究度              │
└───────────────┬────────────────────────┘
                │ 更强阵容
┌───────────────▼────────────────────────┐
│ 时间层：团体战 / 挖矿 / 异色 / 挂机 / 商店 / 蛋   │
└───────────────┬────────────────────────┘
                │ 材料与次数
┌───────────────▼────────────────────────┐
│ 竞技层：赛季 / 排位 / 榜单 / 好友阵容参考        │
└────────────────────────────────────────┘
```

**核心闭环**

```
打比赛（输赢都给研究度） → 徽章/等级上限 + 图鉴等级
        → 解锁设施与收集渠道 → 更强阵容
        → 更高赛季/排位 → 更多研究度
```

## 3. 主线系统（第一阶段）

### 3.1 地区

| 地区 | 对应赛季 | 图鉴范围 | 状态 |
|---|---|---|---|
| 关都 | 第 1 赛季 | 1–151 | 现有内容 |
| 城都 | 第 2 赛季 | 152–251 | 需要新馆主阵容 |
| 丰缘 | 第 3 赛季 | 252–386 | 需要新馆主阵容 |
| 神奥/合众 | 第 4/5 赛季 | 387+ | 暂缓，需补图鉴数据 |

- 赛季 = 地区：一个赛季打完该地区的 8 个道馆、四天王与冠军。
- 冠军后进入下一地区；地区是**配置表驱动**：地图更新到新地区时，只追加一行地区配置，不改代码。
- 现有赛季结构（9 队单循环 + 季后赛 + 四天王）保留；8 场道馆赛各发一枚徽章。
- 后续地区（神奥/合众等）不锁死：可以继续追加，也可以把第 4 地区起改成“全国大赛”复用已有地区、递增难度。

### 3.2 徽章与等级上限

**一个地区固定 20 级。**

| 地区 | 等级段 | 0–1 徽章 | 2–5 徽章 | 6–8 徽章 | 冠军 |
|---|---|---|---|---|---|
| 关都 | Lv1–20 | Lv10 | Lv15 | Lv20 | 城都 Lv21 |
| 城都 | Lv21–40 | Lv30 | Lv35 | Lv40 | 丰缘 Lv41 |
| 丰缘 | Lv41–60 | Lv50 | Lv55 | Lv60 | 下一地区 Lv61 |
| 神奥（预留） | Lv61–80 | Lv70 | Lv75 | Lv80 | 合众 Lv81 |
| 合众（预留） | Lv81–99 | Lv90 | Lv95 | Lv99 | 全国大赛 |

规则：

- 每个地区只开 20 级；0–1 徽章先开到段内第 10 级，2–5 徽章开到第 15 级，6–8 徽章开到第 20 级。
- 冠军后进入下一地区，从下一段第 1 级继续（关都 Lv20 → 城都 Lv21）。
- 达到上限后，经验最多存到“下一级所需经验 −1”，不再升级；界面显示“已满级，先拿徽章”。
- 拿到徽章后，下一次获得经验自动补升。
- 旧档保护：当前等级高于新上限的，不降级；只是暂时不能再升，直到上限追上。
- 四天王/冠军沿用现有解锁逻辑；冠军后 `regionNo + 1`。

**等级上限不是永久锁死：**

- 每个地区的 `lvFrom / lvTo / capTiers` 都写在配置表里，新增地图只追加一行；`levelCap(save)` 按表计算，不写死在代码里。
- 当前关都/城都/丰缘到 Lv60；后续神奥/合众按每地区 +20 继续（61–80、81–99）。
- 如果以后地区超过 5 个、等级段超过 99，再决定是否提高 `MAX_LEVEL`，或改用“地区难度 + 研究度 + 性格”的软上限成长；不需要现在锁死。
- 因此徽章闸门只锁“当前地区的 20 级段”，不锁死游戏寿命；后续地图更新时按配置扩展即可。

### 3.3 徽章解锁设施

在现有可购买槽位之外**额外**解锁，已购买的不变：

| 徽章 | 解锁 |
|---|---|
| 2 枚 | 第 2 个孵蛋槽 |
| 3 枚 | 野球场每日 +1 次 |
| 4 枚 | 商店精灵货架 +1 格 |
| 5 枚 | 训练上限 +5 点 |
| 6 枚 | 第 3 个孵蛋槽 |
| 7 枚 | 商店免费刷新 +1 次/天 |
| 8 枚 | 第 4 个孵蛋槽 + 训练上限 +5 点 |
| 冠军 | 下一地区 + 传说 2 选 1（现有） |

### 3.5 存档与迁移

新增字段：

```js
save.journey.regionNo = 1;          // 当前地区
save.journey.mainQuest = {
  seen: {},                          // 已看过的节点
  claimed: {},                       // 已领取的节点奖励
```

- `levelCap(save)` 由 `regionNo + 徽章数 + champion` 计算，不单独存库。

- 不重置任何成长、图鉴、羁绊。

## 4. 图鉴与钥匙（第三阶段）

### 4.1 研究度

每只精灵 0–100 研究度，作为“强化=收集”的桥：

| 行为 | 研究度 |
|---|---|
| 首次获得 | +20 |
| 进化 | +15 |
| 升到 Lv10 / Lv20 / Lv30（每档一次） | +10 |
| 出战胜利 | +2（每日每只上限 +10） |
| 训练/吃树果 | +1（每日每只上限 +5） |
| 交换获得 | +10 |

- 50 / 100 各领一次奖励：普通树果、高级树果、训练点、孵蛋道具（现有资源）。
- 图鉴卡显示研究度条；满研究度的精灵卡加星。
- 失败也给“出战研究度 +1”，保证输球不空手。

### 4.2 图鉴等级

- 收集点 = 已拥有种数 + 完成研究的种数（每只满 100 算 1 点，理论上限 582）。
- 图鉴等级 = `floor(收集点 / 10) + 1`，上限 30；即 Lv3 需要 20 点、Lv10 需要 90 点、Lv20 需要 190 点。
- 升级自动解锁（不新增货币，专门强化“收集→更容易收集”）：
  - Lv3：追踪目标的商店保底范围扩大
  - Lv5：野球场追踪命中 45% → 55%
  - Lv8：商店追踪上架 65% → 75%
  - Lv10：孵蛋池向追踪目标倾斜
  - Lv12：研究度 50/100 奖励提升一档
  - Lv15：签约价格 −20%
  - Lv20：传说追踪解锁
- 徽章负责“设施与上限”，图鉴等级负责“收集效率”，两条线不重复发同一种槽位。

### 4.3 属性钥匙 / 篇章钥匙

- 每个属性集齐 8 种 → 解锁该属性的“神兽/明星球员”追踪遭遇。
- 每个地区篇章 100% → 解锁地区神兽（关都三鸟、城都三兽、丰缘三柱）。
- 钥匙只解锁“遭遇资格”，不直接送精灵；仍需打赢招募战。
- 属性徽章从“纯展示”升级为“钥匙进度”；UI 显示“还差几只 → 解锁谁”。

### 4.4 图鉴追踪（S83 已删除）

- S54 曾实施：野球场 45%、商店 65%、签约保底；2026-11-26 按用户要求整体移除。
- 与钥匙联动的追踪展示一并取消。

### 4.5 交换

**先做 NPC 交换所，玩家交换后置。**

- 每天 3 个 NPC 报价：用一只己方精灵 + 篮球币，换一只未拥有的同稀有度精灵。
- 通信进化：鬼斯通、勇基拉、隆隆石、机器怪等，交换时消耗一只 + 进化道具，返回进化形态（图鉴点亮）。
- 同种唯一：交换后原精灵离队，不产生重复。
- 玩家间交换需要后端，暂不做；可先做“好友阵容参考/租借”。

## 5. 养成系统（第二阶段）

### 5.1 性格

每只精灵一个性格，影响两项八维（+5% / −5%，cap 99）：

| 性格 | 加成 | 减成 |
|---|---|---|
| 固执 | 投篮 +5% | 传球 −5% |
| 内敛 | 传球 +5% | 投篮 −5% |
| 爽朗 | 速度 +5% | 防守 −5% |
| 淘气 | 防守 +5% | 速度 −5% |
| 勇敢 | 终结 +5% | 控球 −5% |
| 胆小 | 控球 +5% | 终结 −5% |
| 大胆 | 篮板 +5% | 盖帽 −5% |
| 温和 | 盖帽 +5% | 篮板 −5% |

- 获得时随机；蛋孵出的不能改（与口袋冒险一致）。
- 重roll：每日 1 次免费 + 看广告 3 次/天；也可用“性格薄荷”道具。
- 详情页显示性格与加成；队伍页用小标签显示。
- 应用位置：`growthStats` 与 `buildMatchPlayer` 统一乘算，避免两套口径。

### 5.2 宝石（已砍）

原设计为 5 色 × 3 阶 × 3 槽，最多 +9；在 256 点总成长额度里只占约 3.5%，玩家感知弱，却新增“挖矿→合成→镶嵌→UI”四层认知成本。

**定案：不实施宝石。** 强化只保留四条轴：

1. 等级（基础八维）
2. 训练点（定向属性）
3. 性格（±5% 的 build 身份）
4. 进化（新形态/新位置）

如果后期确实需要装备层，另做“2/3 件套词条”（规则级效果），不再做纯数值宝石。

### 5.3 进化道具与挖矿

- 每日 3 次挖矿（广告 +1，最多 1 次）。
- 浅层：篮球币、树果、训练点。
- 深层：进化道具、性格薄荷、孵蛋加速券。
- 保底：每 5 次必出进化道具；每 10 次必出性格薄荷。
- 进化道具：火之石、水之石、雷之石、叶之石、月之石、日之石、金属膜、龙鳞；对应分支进化改为“等级 + 道具”。
- 通信进化走交换所。

### 5.4 糖果与经验

- 现有树果、训练、草地 XP 保留。
- 团体战新增“经验糖果”（小/中/大 = 50/200/800 XP），可喂给任意精灵。
- 研究度与等级共用同一套 XP 结算，避免第三套实现。

## 6. 时间与日常（第三阶段）

### 6.1 团体战

- 每日 1 个 Boss（道馆主/四天王/传说轮换），3 次挑战。
- 全服共享 HP 简化为本地累计：每次按比赛得分折算伤害，3 次打完结算。
- 奖励：经验糖果、进化道具、训练点；击破额外给孵蛋道具。
- 失败也给参与奖励，保证“输也有产出”。

### 6.2 异色狩猎

- 每日 10 次（不是 200 次，手机节奏）。
- 每次进入一场野球场变体，闪光概率 1/512；狩猎场基础概率 1/128。
- 闪光只改外观与图鉴异色页，不改数值。
- 集齐 6 只闪光 → 闪光护符，概率提升到 1/384。

### 6.3 游走神兽

- 每 2–4 小时出现一个 30 分钟窗口；主页提示。
- 每个窗口 1 次遭遇；招募条件：赢 8 分以上。
- 错过窗口进入下一次，不逼在线。

### 6.4 挂机

- 草地保留；新增“夜间球探/特训” 8 小时上限。
- 产出：XP、树果、低概率蛋/进化道具。
- 离线结算最多 8 小时；不做无限挂机。

### 6.5 昼夜与天气

- 现实时间 6:00–18:00 为白天，其余为夜晚。
- 野球场池：白天 一般/草/虫；夜晚 幽灵/恶/超能；水域/洞窟另算。
- 每日天气由“日期 + 地区”决定，提升一个属性 10%（仅野球场）。
- 蛋的花纹/孵化提示随天气变化（纯表现）。

### 6.6 俱乐部日程

替代“每日任务面板”的聚合页：

```
俱乐部日程
[团体战] 3/3    今日 Boss：快龙
[挖矿]   3/3    保底 1 件进化道具
[异色]   10/10  1/512
[游走]   下一次 14:20
[孵化]   1 枚可收取
[草地]   6h 后可收取
```

- 只列“现在能做什么”，不列长任务清单。
- 每个子系统仍有独立次数/时间窗。

## 7. 交换与地区扩展（第四阶段）

## 11. 实施顺序与验收

### 第一阶段：主线 + 徽章闸门

任务：

1. 地区表与 `levelCap`；
2. 统一 XP 上限（4 处调用点）；
3. 徽章设施解锁；
4. 主线页 + 主页主线条；
5. 旧档迁移与回归。

验收：

- 新档主页始终有下一目标；
- 满级提示明确，拿徽章后补升；
- 2/3/4/5/6/7/8 徽章设施逐一生效；
- 冠军 → 城都切换；
- 旧档等级不下降；
- 390×844 无溢出；控制台无报错。

### 第二阶段：性格 + 挖矿 + 团体战

验收：性格可重roll并影响属性；每日挖矿与团体战有产出；失败有参与奖励。

### 第三阶段：图鉴钥匙 + 研究度 + 时间生产

验收：属性/篇章集齐解锁神兽追踪；研究度 50/100 可领；培育屋/异色/游走/挂机/日程上线。

### 第四阶段：交换 + 地区扩展

验收：NPC 交换与通信进化可用；城都/丰缘可完整通关；玩家交换按后端能力决定。

## 12. 风险与未决

1. **等级上限可能挫败**：数值需用现有存档等级分布校准；满级提示必须清楚；旧档不降级。
2. **五地区内容量**：现有 291 只只覆盖三地区；第四/第五地区单独立项。
3. **培育屋/交换与同种唯一冲突**：只允许补未拥有图鉴或换性格，不产生重复个体。
4. **挂机经济通胀**：所有离线产出设 8 小时上限与每日上限。
5. **广告边界**：任何“钥匙”不得进入广告奖励池。
6. **系统过多**：按阶段实施，每阶段完成回归后再开下一阶段；不一次性全上。

### 结论

- **值得原样借鉴**：地区主线、徽章闸门、图鉴当钥匙、交换/通信进化、失败也有产出、广告只卖加速。
- **需要改造**：捕捉概率（不做 1% 折磨）、异色次数（200→10~15）、孵蛋（同种唯一下只做定向池）、日常（加日程聚合）。
- **不借鉴**：宝石纯数值（与训练/道具重复）、黑市/老虎机/柏青哥（合规与成本）、100 层挖矿、五地区一次性铺满（按地图更新逐步加）。
