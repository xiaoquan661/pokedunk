# 05 战术与克制（L2 · 战斗机制）

> 打法层：属性克制怎么用、必杀技、火热手感、防守动作、空接。

## 属性克制（标准 2× / 0.5× / 0×）

克制倍率影响三个交互，普通投篮命中**不受**克制：

| 交互 | 效果 |
| --- | --- |
| 加速冲撞（推人） | 得手概率 ×（0×→0、≥2×→1.5、<1×→0.6），含体型差与 def-hnd |
| 必杀 quake | 范围击倒伤害随克制倍率 |
| 必杀 freeze | 减速 3 + 1.5×倍率 秒 |

实战口诀：**格斗克岩石、水克火**——对位时用克制属性的球员去推人。

展示入口：设置 → 说明 → 系别克制展示完整 18 属性表；赛前对阵页按首发位置列出双方 ×2 属性优势。

## 必杀技（按主属性分 6 类）

| 类别 | 代表招式 | 效果 |
| --- | --- | --- |
| surge | VOLT TACKLE | 回满加速体力 |
| lockin | CALM MIND | 下次出手必完美（扣篮 .99） |
| phase | PHANTOM FORCE | 5 秒免疫抢断/干扰 |
| blaze | BLAST BURN | 立刻点燃火热手感 |
| quake | EARTHQUAKE / HIGH HORSEPOWER | 击倒 14 英尺内所有对手（受克制） |
| freeze | ICY WIND / SLEEP POWDER | 全队减速（受克制） |

槽满按 I/E（触屏 Y）释放。

## 火热手感（On Fire）

- 连进 3 球触发；命中 +0.25、完美窗口 ×1.7、扣篮距离 +4
- 持续 5 次命中后熄灭；对手得分会打断
- 全队播报"IS ON FIRE!"

## 防守动作

| 动作 | 操作 | 数值 |
| --- | --- | --- |
| 抢断 | 近身 ≤4.6 按 L/B | `0.1+(def-hnd)/220`，phase 状态免疫 |
| 盖帽 | 对方出手时起跳 | 覆盖普通投篮与扣篮 |
| 推人 | 加速+抢断（≤4.8） | 成功击倒 1.1 秒；失败耗加速 0.35；1.2% 受伤率（仅训练师之旅） |

## 进攻配合

- **空接（Alley-oop）**：加速+传球，目标距篮 <17 英尺，接球者直接扣篮
- 传球自动选最佳空位，或摇杆指向
- **防守换防**：自动（默认）/ 手动切换对位球员
- 阵容五位置齐：+2 加成；对位算法按位置差平方惩罚
