# 10 · 战斗内数值影响公式

> 目的：单独记录“八维数值 → 比赛内实际行为”的全部现行公式，供调参、平衡讨论和回归测试使用。
> 代码来源：`engine/readable/play-core.js`（函数名标注在每节标题后）。
> 约束：本文记录的是**当前已上线公式**，调整任何系数前先改本文，再改代码。

## 0. 数值进入比赛前的口径

### 0.1 八维来源

```
最终八维 = clamp(种族值 + 等级成长 + 训练点 + 道具点, 1, 99)
```

- 训练：每点 +1；免费点/返还点优先，购买点按价格扣币。
- 道具：每种最多使用 4 次，每次 +1 指定属性，单项 99 封顶。
- 对局开始时会再叠加一次全队加成（位置齐 +2 / 难度 CPU boost），运行时 clamp 到 20–99。

### 0.2 OVR（`calcOVR`）

```
OVR = clamp(round((Σ 属性 × 位置权重 − 60) × 1.25 + 58), 25, 99)
```

位置权重：

| 位置 | 权重 |
| --- | --- |
| PG | spd .20 / sht .20 / pas .20 / hnd .20 / def .10 / ins .10 |
| SG | sht .30 / spd .15 / hnd .15 / ins .15 / def .15 / pas .10 |
| SF | sht .20 / ins .20 / def .20 / spd .15 / reb .10 / blk .10 / pas .05 |
| PF | ins .25 / reb .20 / blk .15 / def .15 / sht .10 / spd .10 / pas .05 |
| C | ins .20 / reb .25 / blk .25 / def .10 / pas .10 / sht .05 / spd .05 |

### 0.3 体力系数（`effort`）

```
energy ≥ 0.55 → effort = 1
energy < 0.55 → effort = 0.82 + 0.18 × (energy / 0.55)
```

最低 0.82，即体力耗尽时所有受 effort 影响的行为只有满体力的 82%。

## 1. 移动速度（`updatePlayer`）

```
基础速度 = (11 + spd × 0.085) × effort
冲刺      × 1.42
必杀加速  × 1.20
减速状态  × 0.55
持球      × 0.94
抢断动作  × 0.50
```

**参考值**

| spd | 基础速度 |
| --- | --- |
| 40 | 14.4 |
| 50 | 15.25 |
| 70 | 16.95 |
| 90 | 18.65 |
| 99 | 19.42 |

- 满速约为 50 速度的 1.27 倍；全区间差异有限，是“手感差异不明显”的首要原因。

## 2. 体力与耐力（`ln` / `tickStamina`）

```
耐力 = clamp(round(35 + reb × 0.45 + def × 0.15), 40, 99)
每帧消耗 = 0.0044 × (1.6 − 耐力/100) + (冲刺中 ? 0.0022 : 0)
```

- 耐力越高，体力下降越慢；体力低于 55% 后通过 `effort` 影响速度、投篮、上篮、扣篮。
- 替补席每秒恢复 0.005（受比赛时钟缩放）。

## 3. 投篮（`baseProb` / `releaseShot` / `contest` / `greenWindow`）

### 3.1 基础命中率

```
近距离（<8）     = 0.55 + ins × 0.004
中距离（8–24）   = clamp(0.20 + sht × 0.0042 − (距离 − 8) × 0.007, 0.10, 0.75)
远距离（>24）    = clamp(0.10 + sht × 0.0037 − (距离 − 24) × 0.03, 0.02, 0.60)
```

### 3.2 按键评价

绿窗（`greenWindow`）：

```
绿窗 = (0.022 + sht/100 × 0.034) × 难度系数 × (火热 ? 1.7 : 1)
```

评价判定：

| 误差范围 | 评价 |
| --- | --- |
| ≤ 绿窗 | perfect |
| ≤ 绿窗 × 2.3 | good |
| ≤ 绿窗 × 4.5 | early / late |
| 更大 | very-early / very-late |

### 3.3 最终命中率（`releaseShot`）

```
perfect   = (三分线外 ? 0.86 : 0.94) − (1 − 干扰系数) × 0.55
good      = 基础命中 × 干扰系数 + 0.06
early/late= 基础命中 × 干扰系数 × 0.80
very-*    = 基础命中 × 干扰系数 × 0.30
```

修正：

```
× (0.7 + 0.3 × effort)
火热状态 +0.25
距离 > 35：perfect 最多 0.25，其余最多 0.04
```

### 3.4 干扰（`contest`）

对 7 英尺内每名防守者：

```
单人干扰 = (1 − 距离/7) × (0.25 + def × 0.0025 + 体型 × 0.06)
防守者在投篮者身后：× 0.6
干扰 = 所有防守者的最大值
干扰系数 = clamp(1 − 干扰, 0.35, 1)
```

人类玩家再乘难度系数 `diff.contest`。

## 4. 上篮（`releaseLayup`）

```
命中 = (0.55 + ins × 0.004) × (0.45 + 0.55 × 干扰系数) × (0.7 + 0.3 × effort)
火热 +0.20
```

## 5. 扣篮（`startDunk` / `dunkRange`）

```
命中 = clamp(0.50 + ins × 0.0035 − (1 − 干扰系数) × 0.6, 0.30, 0.93) × (0.7 + 0.3 × effort)
火热 / 锁定 = 0.99
扣篮范围 = 3 + ins × 0.09（火热再 +4）
```

| ins | 扣篮范围 |
| --- | --- |
| 50 | 7.5 |
| 70 | 9.3 |
| 90 | 11.1 |

## 6. 盖帽（`updateDunk` / `updateShot`）

### 6.1 跳投篮 / 上篮

```
盖帽率 = clamp(0.15 + blk × 0.004 − 投篮者 sht × 0.002 − (跳投 ? 0.05 : 0), 0.05, 0.60)
```

### 6.2 扣篮

```
盖帽率 = clamp(0.25 + blk × 0.004 − 扣篮者 ins × 0.0025 + (体型差) × 0.3, 0.08, 0.55)
```

### 6.3 起跳高度

```
垂直初速 = 14 + max(blk, reb) × 0.05
```

## 7. 抢断（`trySteal` / `updatePass`）

### 7.1 持球抢断

```
成功率 = clamp(0.10 + (抢断者 def − 持球者 hnd) / 220, 0.03, 0.38)
对方处于投篮 / 上篮动作 × 0.4
必杀相位 = 0
```

- 常规抢断距离 4.6；冲刺/怒气状态下推撞判定距离 4.8。
- 抢断冷却 0.6 秒。

### 7.2 传球拦截

```
拦截率 = clamp(0.08 + (拦截者 def − 传球者 pas) / 200 + (人类按下抢断 ? 0.20 : 0), 0.03, 0.40)
空中接力且拦截者未起跳 × 0.2
```

## 8. 卡位 / 推撞（`trySteal` 推撞分支）

```
成功率 = clamp(0.55 + (体型差) × 0.8 + (def − 对方 hnd) / 250, 0, 0.95)
属性克制：克制 ×1.5 / 被克 ×0.6 / 无效 ×0
```

- 推撞成功后对方进入 1.1 秒硬直。

## 9. 篮板（`loosePickup`）

```
抢板评分 = reb + 随机(0, 35) + (起跳高度 > 0.5 ? 10 : 0)
评分最高者拿球
```

- 35 点随机浮动会明显压缩高篮板与低篮板的差距。

## 10. 传球（`attemptPass`）

```
传球速度 = 46 + pas × 0.16
空中接力 = 32（固定速度）
```

## 11. AI 防守反应（`reactTime`）

```
反应时间 = 基础值 + (100 − def)/100 × 0.25 + 随机(0, 0.08)
```

| def | 额外反应时间 |
| --- | --- |
| 40 | 0.150 秒 |
| 70 | 0.075 秒 |
| 99 | 0.0025 秒 |

## 12. 属性克制（`Va` / 推撞）

- 只影响推撞成功率与地震/冰冻类必杀的击退与减速；
- 不影响投篮基础命中；
- 推撞倍率：克制 ×1.5、被克 ×0.6、无效 ×0。

## 13. 各属性每 +10 点的实际增量

| 属性 | 主要作用 | 每 +10 点增量 |
| --- | --- | --- |
| spd | 移动速度 | 基础速度 +0.85（约 +5%） |
| sht | 中距离命中 | 命中率 +4.2 个百分点 |
| sht | 绿窗 | +0.0034 秒 |
| sht | 盖帽抵抗 | 被盖率 −2 个百分点 |
| ins | 近距命中 | +4 个百分点 |
| ins | 上篮 | +4 个百分点 × 干扰 |
| ins | 扣篮 | +3.5 个百分点 × 干扰 |
| ins | 扣篮范围 | +0.9 英尺 |
| pas | 传球速度 | +1.6 |
| pas | 被拦截抵抗 | 拦截率 −5 个百分点 |
| def | 干扰 | 单人最高 +2.5 个百分点 |
| def | 持球抢断 | +4.5 个百分点 |
| def | 传球拦截 | +5 个百分点 |
| def | 反应时间 | −0.025 秒 |
| blk | 盖帽率 | +4 个百分点 |
| blk | 起跳高度 | +0.5 初速 |
| reb | 篮板评分 | +10（但随机 ±35） |
| reb | 耐力 | +4.5 耐力值 |
| hnd | 被抢断抵抗 | 抢断率 −4.5 个百分点 |
| hnd | 被推撞抵抗 | 推撞率 −4 个百分点 |

## 14. 已知的“差异被吃掉”位置

1. **移动速度**：全区间只有约 1.27 倍差异。
2. **绿窗**：sht 50 → 99 仅增加约 0.017 秒。
3. **篮板**：固定 35 点随机，相当于 35 点属性差。
4. **抢断**：成功率有 0.03–0.38 硬上下限。
5. **盖帽 / 干扰**：同样有硬上下限，满值后继续堆属性收益归零。
6. **投篮**：完美评价时干扰只按 55% 折扣，属性差被评价档位覆盖。

## 15. 调参建议入口（未实施）

如要让体感差异更明显，优先调整以下系数，并同步更新本文：

| 目标 | 位置 | 建议方向 |
| --- | --- | --- |
| 速度差更明显 | `updatePlayer` 的 `11 + spd × 0.085` | 提高 spd 斜率或降低基础值 |
| 投篮手感差异 | `greenWindow` 的 `0.022 + sht/100 × 0.034` | 扩大 sht 对绿窗的斜率 |
| 篮板差异 | `loosePickup` 的 `rng() × 35` | 降低随机浮动 |
| 抢断差异 | `trySteal` 的 `/220` 与上下限 | 提高斜率、放宽上限 |
| 盖帽差异 | `updateShot` / `updateDunk` 的 blk 系数 | 提高 blk 斜率或降低 sht/ins 抵扣 |
